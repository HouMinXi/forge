**cli/gap_detector.py**: Core gap detection pipeline.

File header: SPDX + Copyright. Docstring: "Gap detection pipeline -- dedup, D4 three-outcome classification, storage (D3/D4)."

**Loader functions** (same pattern as load_findings in forge_cli.py):
- `load_external_findings()`: returns `{'version': 1, 'findings': []}` on missing/corrupt
- `load_gap_candidates()`: returns `{'version': 1, 'candidates': []}` on missing/corrupt
- `load_keyword_expansion_queue()`: returns `{'version': 1, 'expansions': []}` on missing/corrupt

**Dedup functions:**

`is_exact_dup(source, source_id, existing_findings) -> bool`:
- Check if any existing finding matches both `source` and `source_id`.
- Match = skip entirely, no audit trail (per D3 exact dedup spec).

`find_cross_source_dup(file_val, line_val, text_hash, timestamp_str, existing_findings) -> Optional[str]`:
- If `file_val is None` or `line_val is None`: return None immediately (general comments without file/line context cannot be cross-source deduped -- two unrelated "LGTM" comments would falsely match).
- Look for any existing finding within 7 days before `timestamp_str` where file, line, and text_hash all match.
- Parse timestamps with `datetime.fromisoformat()` (for Python 3.10 compat: replace trailing `Z` with `+00:00` before parsing, same pattern as Outcome 1 last_seen comparison).
- Return the original finding's `id` if found, else None.
- When original found: return the earliest-timestamp match. Ties broken by source priority: github_pr > git_log > ci_log (implement as priority dict: `{'github_pr': 0, 'git_log': 1, 'ci_log': 2}`).

**D4 Classification:**

`classify_finding(finding_dict, keyword_dicts, dimension_states) -> Tuple[str, Optional[str]]`:
- Build search_text: `((finding_dict.get('dimension_raw') or '').strip() + ' ' + (finding_dict.get('text') or '')).lower()`
- Step 1: For each non-archived dim in keyword_dicts (check dimension_states for status; missing from dimension_states = treat as active per fallback): count distinct keywords that appear as case-insensitive substrings in search_text. Each keyword counted at most once.
- Step 2: If no non-archived dims exist -> return ('outcome_3', None)
- Step 3: If max(count) > 0 -> collect all dims with max count, pick `min(candidates)` (alphabetically first). Return ('outcome_1', selected_dim). This ensures deterministic tiebreaking regardless of dict iteration order.
- Step 4: If max(count) == 0 and `(finding_dict.get('dimension_raw') or '').strip().lower()` exactly equals some non-archived dim key -> return ('outcome_2', that_dim)
- Step 5: Otherwise -> return ('outcome_3', None)

**Main processing function:**

`process_learn(adapter_findings)`:
- `adapter_findings`: List[Tuple[CanonicalFinding, ExtractedFinding]] from llm_parser.extract_findings()
- **Lazy imports inside this function** to avoid circular imports (forge_cli -> gap_detector -> forge_cli): `from forge_cli import load_config, atomic_write, CONFIG_FILE, FINDINGS_FILE`, `from migration import run_migration_if_needed, ensure_dimension_state`, and `from llm_parser import compute_text_hash`.
- Load all storage files: external_findings, gap_candidates, keyword_expansion_queue, config (via `load_config()`).
- Run migration if needed: check if 'dimension_states' not in config, call `run_migration_if_needed(CONFIG_FILE, FINDINGS_FILE)`. Note: `run_migration_if_needed` handles its own load/write of both config and internal findings. After calling it, reload config via `config = load_config()` to pick up any changes (e.g., newly created dimension_states on first run).
- For each (canonical, extracted) pair:
  1. Build finding dict for external_findings.json:
     - `id = f"ext-{uuid.uuid4()}"`
     - Copy adapter-set fields from canonical: source, source_tool, source_id, timestamp, context, raw_source
     - Copy LLM-extracted fields from extracted: dimension_raw, confidence, suggested_keywords, text, file, line
     - Set initial values: `validated_dimension=None`, `gap=False`, `dedup_of=None`, `text_hash=compute_text_hash(extracted.text)`
  2. Exact dedup: if `is_exact_dup(canonical.source, canonical.source_id, ext_data['findings'])`: skip entirely, continue.
  3. Cross-source dedup BEFORE appending: `dup_id = find_cross_source_dup(...)` against existing `ext_data['findings']` (does NOT include current finding since it hasn't been appended yet). If dup_id: set `finding['dedup_of'] = dup_id`, do NOT pass to D4.
  4. Store finding in external_findings (append to ext_data['findings']) -- AFTER dedup check to avoid self-match.
  5. If dedup_of is None: run D4 classification.
  6. Process outcome:
     - **Outcome 1** (keyword match): `finding['validated_dimension'] = dim`, `finding['gap'] = False`. Update dimension_states: `ensure_dimension_state(config, dim)`, increment finding_count, update last_seen: if current last_seen is None, set to `finding['timestamp']`; otherwise compare via `datetime.fromisoformat()` parsing (handles both `+00:00` and `Z` suffixes correctly in Python 3.11+; for Python 3.10 compat, replace trailing `Z` with `+00:00` before parsing). Set last_seen to the chronologically later timestamp string. This prevents processing old PRs after new ones from regressing last_seen.
     - **Outcome 2** (name match, keywords don't match): `finding['validated_dimension']` stays None, `finding['gap']` stays False. Create keyword_expansion_queue entry: `id=f"exp-{uuid.uuid4()}"`, finding_id=finding['id'], created_at=now, proposed_dimension=matched_dim, unmatched_text=finding['text'], text_hash=finding['text_hash'], suggested_keywords=finding['suggested_keywords'], status="pending", reclassified_to=None. Note: keyword_expansion_queue also serves as an audit trail for reclassify actions (Plan 04). Reclassify writes entries with `status="approved"` to record the reclassification decision.
     - **Outcome 3** (unrecognized): `finding['validated_dimension'] = "unknown"`, `finding['gap'] = True`. Create gap_candidate: `id=f"gap-{uuid.uuid4()}"`, finding_id=finding['id'], timestamp=finding['timestamp'], created_at=now, dimension_raw=finding['dimension_raw'], text=finding['text'], text_hash=finding['text_hash'], file=finding['file'], line=finding['line'], source=finding['source'], status="pending", group_id=None, reclassified_from=None.
- After processing all findings: atomic_write all modified files (external_findings, gap_candidates, keyword_expansion_queue, config).
- Print summary: "forge: learned {N} findings ({o1} matched, {o2} expansion, {o3} gap, {dup} duplicates)"

```python
elif args.learn:
    if not any([args.pr, args.branch, args.ci_file]):
        parser.error(
            '--learn requires exactly one of: --pr, --branch, --ci-file'
        )
    source_count = sum(bool(x) for x in [args.pr, args.branch, args.ci_file])
    if source_count > 1:
        parser.error(
            '--learn requires exactly one of: --pr, --branch, --ci-file'
        )
    from adapters.github_pr import GitHubPRAdapter
    from adapters.git_log import GitLogAdapter
    from adapters.ci_log import CILogAdapter
    from llm_parser import extract_findings
    from gap_detector import process_learn

    if args.pr:
        adapter = GitHubPRAdapter()
        canonical = adapter.fetch(args.pr)
    elif args.branch:
        adapter = GitLogAdapter()
        canonical = adapter.fetch(args.branch)
    else:
        adapter = CILogAdapter()
        canonical = adapter.fetch(args.ci_file)

    if not canonical:
        print("forge: no findings to process from source", file=sys.stderr)
        sys.exit(0)

    parsed = extract_findings(canonical)
    if not parsed:
        print("forge: LLM parsing produced no results", file=sys.stderr)
        sys.exit(0)

    process_learn(parsed)
```

Note: imports are inside the elif branch (lazy import) to avoid loading adapters/LLM modules when other commands are used. This matches the existing pattern where forge_cli does not import yaml at module level but inside try/except.
