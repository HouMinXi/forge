## THE CANDIDATE EXPLANATIONS

Distinguish these by experiment. They are not equally likely and they
are not mutually exclusive -- more than one can be true at once, and
saying which ones are true is the deliverable.

  H1 MODE. _finalize_local_terminal implies LOCAL mode. If reviews here
     run in CI mode, the writer is never reached at all. Cheap to test
     and, if true, means the ledger is structurally unreachable for the
     way forge is actually run -- not a bug in the writer.

  H2 WORKTREE. Rows are written to <cwd>/.code-forge/ledger.jsonl, and
     this project MANDATES working in linked worktrees which are removed
     after merge. If cwd is the worktree, every row ever written died
     with its worktree. Note this repo lost a receipt set to exactly
     that mechanism earlier today, so the failure mode is proven to
     exist here.

  H3 EARLY RETURN. base_sha or head_sha is None in practice, so G4
     returns 0 without writing and without logging.

  H4 DISPOSITION. Findings never actually reach FIXED or DISMISSED, so
     G5's `continue` skips every one.

  H5 Something else, or a combination.

Do not rank these from reading the code. Rank them from what you
measured. If an experiment cannot separate two of them, say so rather
than picking the more plausible one.
