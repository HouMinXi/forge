<objective>
Implement Outlet C (subagent) orchestrator that routes through StateMachine, producing
receipts that code-forge verify can validate. Wire it into cli.py replacing the early
Verdict.PASS stub. Critically: collect code_excerpts from reviewer JSON and pass them
through to receipt.py via l1_provider 4-tuple so verify check 5 can validate per-hunk coverage.
No post_round_hook overwrite needed -- excerpts flow through the l1_provider channel.

Purpose: Close the Outlet C receipt gap (SHRK-01). Currently cli.py:690-692 returns
Verdict.PASS without producing any receipts when outlet=subagent. This makes code-forge
verify meaningless for subagent-driven reviews. The fix routes Outlet C through the same
StateMachine that Outlet A uses, ensuring identical receipt and cycle-counting behavior.

CRITICAL integration chain per CONTEXT.md and B2 fix:
1. Reviewer (via SKILL.md) outputs JSON with both findings and code_excerpts fields
2. outlet_c.py collects this JSON and passes BOTH to StateMachine/receipt.py
3. receipt.py assembles reviewer-provided excerpts (does NOT generate them, no disk read)
4. verify.py check 5 verifies per-hunk coverage from assembled excerpts vs diff post-image
5. verify.py check 6 derives coverage from assembled excerpt lines vs diff lines

Output: outlet_c.py module, cli.py wiring, test_outlet_c.py with mechanical guarantee
tests (cases A and B from CONTEXT.md) and excerpt flow integration test (H3).
</objective>
