### T3: 5 real_api E2E tests

Add to tests/test_cli_integration.py, following existing test_mimo_real_api_call
pattern (line 735). Each test:

1. Construct BackendConfig from fixture values (NOT from gate.yaml file)
2. Skip if API key env var not set: pytest.skip("KEY not set")
3. Call llm_invoke(minimal_prompt, backend=cfg)
4. Assert isinstance(result, LLMResult)
5. Assert isinstance(result.content, dict) (parsed JSON, not string)
6. Assert result.usage.input_tokens > 0
7. Assert result.usage.output_tokens > 0

New tests (all @pytest.mark.real_api):
- test_deepseek_real_api_call (openai format, DEEPSEEK_API_KEY)
- test_kimi_real_api_call (anthropic format, KIMI_API_KEY)
