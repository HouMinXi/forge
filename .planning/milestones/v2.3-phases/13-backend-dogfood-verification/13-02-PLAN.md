# Phase 13 Plan 02: SARIF Token Cost Properties

**Wave:** 2
**Goal:** Add tokenCost to SARIF output in runs[0].properties
**Depends on:** Plan 01 (verified backends needed for cost data)

## Design Decisions (from review feedback)

- tokenCost is OMITTED for cli backends (Usage(0,0) is meaningless)
- Only emitted when backend.type == "api"
- passes = number of L1 review passes executed (not cycle count)
- Task order: T1 (sarif.py) -> T2 (unit test) -> T3 (wire cli.py)
- build_sarif_log gains backend_name/backend_model params (not a pre-built dict)
- tokenCost dict is constructed INSIDE _emit_ci_output where final_state
  is already loaded (line 74), avoiding scope issues at the call site

## Tasks

### T1: Add tokenCost construction to build_sarif_log

Modify sarif.py build_sarif_log() to accept optional backend info:

```python
def build_sarif_log(state, tool_versions, forge_version,
                    backend_name=None, backend_model=None):
    ...
    run = _build_run(state, tool_versions, forge_version)
    if backend_name is not None and state.cost_passes > 0:
        run.setdefault("properties", {})["tokenCost"] = {
            "inputTokens": state.cost_total_input,
            "outputTokens": state.cost_total_output,
            "totalTokens": state.cost_total_input + state.cost_total_output,
            "backend": backend_name,
            "model": backend_model or "",
            "passes": state.cost_passes,
            "durationSeconds": round(state.cost_total_duration, 1),
        }
    return {"$schema": ..., "version": ..., "runs": [run]}
```

Key points:
- state (which has cost_total_input etc.) is ALREADY a parameter
- backend_name=None means cli backend -> no tokenCost emitted
- _build_run signature unchanged

**Files:** src/code_forge/sarif.py
**Verify:** python -m py_compile src/code_forge/sarif.py

### T3: Wire backend info from cli.py _emit_ci_output call site

At cli.py line 842, _emit_ci_output is called inside _run().
The resolved backend is in scope at this point (line ~753).

Change: pass backend_name and backend_model to _emit_ci_output,
which forwards them to build_sarif_log.

```python
# cli.py _emit_ci_output signature change:
def _emit_ci_output(state_path, registry, post_emit_hook=None,
                    backend_name=None, backend_model=None):
    ...
    log_dict = build_sarif_log(
        final_state, tool_versions, forge_version,
        backend_name=backend_name, backend_model=backend_model,
    )

# Call site in _run() (line ~842):
_emit_ci_output(
    state_path, registry,
    backend_name=backend.name if backend.type == "api" else None,
    backend_model=backend.model if backend.type == "api" else None,

```

This is the ONLY call site for _emit_ci_output in the codebase.
No _run_hold_loop threading needed (_run_hold_loop does NOT call
_emit_ci_output).
