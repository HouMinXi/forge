<objective>
Wire the tiering threshold through the full call chain (cli.py -> outlets ->
StateMachine) and fix the F3 false-green defect by tagging infrastructure
error findings as source="INFRA" and skipping the falsifier for them.

Purpose: This connects Plan 01's pure functions to the actual review pipeline.
The threshold flows: cli.py computes it once -> threads to outlet dispatch ->
StateMachine uses it for convergence. The F3 fix prevents error-path findings
(invoke-fail, schema-fail, spawn-fail) from being dismissed by the LLM
falsifier, which caused false-green results on large diffs.

Output: Threshold wiring across 4 source files, F3 fix (4 INFRA source tags + 1 falsifier skip guard), 8 new tests.
</objective>
