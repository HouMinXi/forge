    Orchestrates Stage 1 + Stage 2 with caching.
    [ADDRESSES: B-03, H-05, L-R2-03, L-R4-08]

    cache files in cwd/".code-forge"/"conventions-cache"/. For each .json file,
    extract the path_hash prefix (before the first underscore). Collect the set of
    path_hashes from the current source list. Delete any cache file whose
    path_hash is not in the current sources set. This prevents dead entries from
    accumulating when sibling repos are removed from configuration.

    For each source:
    1. Compute cache key using CORRECT sha256 (B-03):
       path_hash = hashlib.sha256(str(source.repo_path).encode()).hexdigest()[:12]
       NOT sha256(str(...)) which is a TypeError.
    2. Get commit hash via git subprocess (H-05 full spec):
       try:
           proc = subprocess.run(
               ["git", "-C", str(source.repo_path), "rev-parse", "HEAD"],
               capture_output=True,
               text=True,
               timeout=5,
               check=False,
           )
           commit_hash = proc.stdout.strip() if proc.returncode == 0 else "no-git"
       except (subprocess.TimeoutExpired, FileNotFoundError):
           commit_hash = "no-git"
    3. Check cache dir cwd/".code-forge"/"conventions-cache"/. Look for file named
       "{path_hash}_{commit_hash}.json".
    4. If cache hit: read the cached digest string from the JSON file (json.loads).
    5. If cache miss: call extract_conventions(source), write result to cache file as
       JSON {"digest": "...", "repo": str(source.repo_path), "commit": commit_hash}.
       Before writing, delete any stale cache files for the same path_hash:
       glob for "{path_hash}_*.json" in cache dir, delete each.
       Create cache dir (parents=True, exist_ok=True) on first write.

    Concatenate non-empty digests (L-R4-08): filter out empty strings before joining
    to avoid extra "\n\n" noise from sources that resolved but produced no names:
      "\n\n".join(d for d in digests if d)
    Return the combined string, or "" if no sources resolved or all digests empty.
