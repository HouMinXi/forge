    Semantic validation in validate_siblings(siblings_list, gate_yaml_dir):
    - siblings_list not a list -> ValueError("siblings: must be a list")
    - Each entry missing repo: -> ValueError("siblings[N]: 'repo' is required")
    - Each entry missing ref: -> ValueError("siblings[N]: 'ref' is required")
    - ref: does not contain ".." -> ValueError("siblings[N]: ref must be 'baseline..head'")

    - label: defaults to basename of repo: path when absent
    - Duplicate labels after defaulting -> ValueError("siblings: duplicate label 'X'")
    - Label equals "primary" (case-sensitive) -> ValueError("siblings: label 'primary' is reserved")
    - label: contains characters other than alphanumeric, hyphen, or underscore -> ValueError("siblings[N]: label must be alphanumeric/hyphen/underscore only")

      If provided and sibling's detect_toolchain().language != primary_language ->
      ValueError("siblings[N]: sibling detected as '<lang>' but primary is '<primary>'; same-stack only for v1")
      D-09 note: primary_language is passed from the call site in load_gate_config only
