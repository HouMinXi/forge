    In state.py line 48: change source Literal["L0", "L1"] to Literal["L0", "L1", "MUTANT"]. This is the only change to state.py -- additive, no schema version bump needed (per D2 convention established in Phase 1).

    Create src/forge/mutation.py as a new module. This module owns all mutmut subprocess calls (per D-02: keep subprocess in one place so future language runners can replace without changing the l2_runner interface).

    The module must contain:

    1. A Survivor namedtuple or dataclass with fields: file (str), mutant_id (int).

    2. A parse_mutmut_results(stdout: str) function that parses mutmut 3.x output format. Expected format from mutmut results:
       "Survived (N)\n---- ./file.py (M) ----\nid1, id2-id3\n"
       Returns list[Survivor]. Handle ranges (1-3 means IDs 1,2,3) and comma-separated IDs. Return empty list on empty/unparseable input (never raise).

    3. A run_mutation(diff_files: list[str], baseline_cmd: list[str], timeout: int = 600) function. Signature returns tuple[list[StateFinding], list[str]] (findings, infra_errors) -- same shape as l0_runner for consistency.

       Implementation flow per CONTEXT.md D-02 and D-05:
       a. If not diff_files: return empty (no files to mutate).
       b. Filter diff_files to .py files only (Python-only MVP per SPEC). If zero .py files remain, return a single MUTATION_SKIPPED finding with disposition=DISMISSED and description indicating unsupported language, plus infra_errors=["no Python files in diff"].
       c. Flaky guard: run baseline_cmd 3 times via subprocess.run with capture_output=True, text=True, timeout=120, check=False. If any run has returncode != 0, return MUTATION_SKIPPED finding (disposition=DISMISSED, description="tests flaky, mutation unreliable (3x baseline check)") plus infra_errors=["flaky guard: baseline failed on run N"].
       d. Check shutil.which("mutmut"). If None, return MUTATION_SKIPPED finding (disposition=DISMISSED, description="mutmut not installed (soft dependency)") per D-05.
       e. Run mutmut: subprocess.run(["mutmut", "run", "--paths-to-mutate"] + py_files, capture_output=True, text=True, timeout=timeout, check=False). On timeout (subprocess.TimeoutExpired), return MUTATION_SKIPPED finding with description="mutmut timed out after Ns".
       f. Run mutmut results: subprocess.run(["mutmut", "results"], capture_output=True, text=True, timeout=10, check=False). Parse stdout with parse_mutmut_results.
       g. For each Survivor, create StateFinding with: id="mutant-FILE-ID", fingerprint="mutant:FILE:ID" (file relative, ID numeric), source="MUTANT", disposition=CONFIRMED, file=survivor.file, line_range=[0, 0] (mutmut does not reliably report line numbers), description="mutant ID survived in FILE".
       h. Return (findings, []).

    All MUTATION_SKIPPED findings use: id="MUTATION_SKIPPED", source="MUTANT", disposition=DISMISSED, file="", line_range=[], evidence_files=[]. Use a stable fingerprint per skip reason (e.g. "mutation-flaky", "mutation-unavailable", "mutation-no-python", "mutation-timeout").

    Use subprocess.run with list args, never shell=True. Import shutil for which() check.
  </action>
