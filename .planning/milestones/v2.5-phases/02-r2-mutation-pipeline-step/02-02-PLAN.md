    Part D -- LOCAL consecutive_survivor_rounds (machine.py):

    In _run_local, after self._execute_round(round_index):
       Count CONFIRMED MUTANT findings in current state: mutant_survivors = sum(1 for f in self._state.findings if f.source == "MUTANT" and f.disposition == Disposition.CONFIRMED).
       If mutant_survivors > 0: self._state.consecutive_survivor_rounds += 1.
       If mutant_survivors == 0: self._state.consecutive_survivor_rounds = 0.
       If self._state.consecutive_survivor_rounds >= 3: set self._state.verdict = Verdict.FAIL, self._state.converged = False, append "mutation: 3 consecutive rounds with survivors -- tests are demonstrably weak" to infra_errors, self._persist_state(), return Verdict.FAIL.
       This check goes BEFORE the _fixpoint_reached() check (survivors prevent fixpoint anyway, but the consecutive counter is the resource guard that hard-stops).

    Part E -- CI async mutation (machine.py):

    In _run_ci, after the existing _execute_round(round_index=0):

    1. Check for prior mutation result: read self.cwd / ".forge" / "mutation-result.json". If exists, json.load it. Validate schema (must have "status" key).
       - If status == "done" and survivors list is non-empty: set verdict=FAIL, converged=False, append "CI: mutation survivors found: N survivors" to infra_errors, persist and return Verdict.FAIL.
       - If status == "running" and PID alive (os.kill(pid, 0) succeeds): SKIP launch -- mutation is still in progress. Log to infra_errors "CI: mutation PID N still running, skipping new launch". Proceed to normal L0+L1 verdict.
       - If status == "running" and PID dead (ProcessLookupError): treat as error, append MUTATION_SKIPPED finding with source="MUTANT", disposition=DISMISSED, description="CI: mutation process died (PID N)". Delete stale result file.
       - If status == "error": set verdict=FAIL, append error detail to infra_errors, persist and return Verdict.FAIL.

    2. Launch new async mutation (only if step 1 did not return early or skip):
       get diff_files from self._source_files(), filter to .py. If no Python files, skip. If shutil.which("mutmut") is None, write mutation-result.json with {status: "error", message: "mutmut not installed"} and skip.
       Otherwise: launch a WRAPPER THREAD (threading.Thread) that:
         (a) Runs subprocess.run(["mutmut", "run", "--paths-to-mutate"] + py_files, capture_output=True, env={...PYTHONPATH: "src"...})
         (b) On success (exit 0 or 2): runs subprocess.run(["mutmut", "results"], capture_output=True) and parses survivor lines
         (c) Writes mutation-result.json with {pid: original_pid, started_at: ..., status: "done", survivors: [...parsed list...]}
         (d) On failure: writes mutation-result.json with {status: "error", message: stderr}
       The wrapper thread is daemon=True so it does not block process exit.
       Write initial mutation-result.json with {pid: thread_ident, started_at: time.time(), status: "running", survivors: []}.

    3. Proceed with normal L0+L1 verdict determination (existing code). The wrapper thread runs in background.

    Import additions at top of machine.py: import json, import time, import os, import threading (only if not already imported).
