    1. Install mutmut if not present: pip install "mutmut>=3.5.0"
    2. Run mutmut on mutation.py: mutmut run --paths-to-mutate src/forge/mutation.py --tests-dir tests/
       (with PYTHONPATH=src in environment)
    3. Check results: mutmut results
    4. If survivors exist: examine each with mutmut show ID. Determine if the survivor is:

    Note: mutmut may run slowly on machine.py due to its size. Use --paths-to-mutate to scope to specific files. If mutmut is unavailable (cannot install), document the skip and note it as a follow-up.
