<objective>
Add the `command` field to BackendConfig and generalize llm_invoke.py to dispatch by backend type (cli subprocess vs api HTTP). This is the GA2 foundation that enables both Outlet A (CLI) and future api-type backends.

Purpose: Without this, llm_invoke is hardcoded to `claude -p`. After this plan, any configured backend (cli with custom binary, or api with openai/anthropic format) can execute LLM calls. Per D-04/D-05/D-06/D-07/D-08.

Output: Modified backend.py (command field), rewritten llm_invoke.py (dual dispatch), updated tests.
</objective>

<task type="auto">
  <name>Task 2: Generalize llm_invoke to dispatch by BackendConfig</name>
  <files>src/code_forge/llm_invoke.py, tests/test_llm_invoke.py</files>
  <action>
  Rewrite llm_invoke signature to: `llm_invoke(prompt: str, backend: Optional[BackendConfig] = None, timeout_s: int = DEFAULT_TIMEOUT_S) -> Any`. Import BackendConfig and DEFAULT_BACKEND from `.backend`. When backend is None, use DEFAULT_BACKEND (preserves backward compat for callers that do not pass backend yet -- callers are updated in Plan 07-02).

  Dispatch by `backend.type`:

  **cli path** (backend.type == "cli"):
  Refactor existing subprocess logic. Binary: if `backend.command` is non-empty, use `shutil.which(backend.command)`, raising LLMInvokeError if not found. If empty, use `shutil.which("claude")` (existing behavior). Model: if `backend.model` is non-empty, use it. If empty, use `_resolve_model()` (existing FORGE_LLM_MODEL fallback). The rest of the subprocess logic (large-prompt temp file, timeout, JSON fence stripping) stays identical.

  **api path** (backend.type == "api"):
  Use `urllib.request.urlopen` with `urllib.request.Request` (stdlib only, no new deps).

  For `backend.format == "openai"`:
  - URL: `backend.base_url + "/chat/completions"` (base_url includes version prefix, e.g. https://api.deepseek.com/v1)
  - Headers: `{"Authorization": "Bearer " + api_key, "Content-Type": "application/json"}`
  - Body: `{"model": backend.model, "messages": [{"role": "user", "content": prompt}], "temperature": 0}`
  - Response: parse JSON, extract `choices[0].message.content`, then parse that content string as JSON (apply fence-stripping)

  For `backend.format == "anthropic"`:
  - URL: `backend.base_url + "/v1/messages"` (base_url is host only, e.g. https://api.anthropic.com)
  - Headers: `{"x-api-key": api_key, "anthropic-version": "2023-06-01", "Content-Type": "application/json"}`
  - Body: `{"model": backend.model, "max_tokens": 4096, "messages": [{"role": "user", "content": prompt}]}`
  - Response: parse JSON, extract `content[0].text`, then parse that content string as JSON (apply fence-stripping)

  Wrap response content extraction in try/except (KeyError, IndexError, TypeError) and raise LLMInvokeError('unexpected response structure from %s backend' % backend.format) on any access error. This converts provider-specific structure errors into the standard LLMInvokeError that callers handle.

  For both api formats: look up `api_key = os.environ.get(backend.api_key_env, "")`. If empty, raise LLMInvokeError with message naming the missing env var (e.g. "API key env var %r is not set"). Wrap `urlopen` in try/except for `urllib.error.URLError` and `urllib.error.HTTPError`, converting to LLMInvokeError with status code and body excerpt. Use `timeout=timeout_s` on the urlopen call.

  For unknown backend.type, raise LLMInvokeError("unsupported backend type: %r" % backend.type).

  Replace the `model: Optional[str] = None` parameter with `backend: Optional[BackendConfig] = None`. The model information moves into `backend.model`. Existing callers passing no model kwarg are unaffected (backend=None defaults to DEFAULT_BACKEND). Update existing tests that pass model= kwarg: replace model='X' with backend=BackendConfig(type='cli', model='X', command='', ...) or create a test helper. Specifically, test_llm_invoke.py:19 uses model='claude-sonnet-4-6' which must be migrated. The `_resolve_model()` private helper stays (used internally by the cli path when backend.model is empty). Remove standalone `_resolve_claude_binary()` -- inline its logic into the cli dispatch branch using `backend.command or "claude"` as the which-target. Update tests/test_llm_invoke.py: update test_raises_when_claude_not_found (in TestLLMInvoke class): _resolve_claude_binary is tested indirectly via test_raises_when_claude_not_found -- this test continues to pass after inlining the binary resolution into the cli dispatch branch -- its subject function no longer exists. The equivalent logic (which lookup + LLMInvokeError) is now tested via test_cli_dispatch_* tests.

  Extract the markdown-fence stripping logic into a private `_strip_fences(text: str) -> str` helper, called from both cli and api result-parsing paths.

  Add tests in test_llm_invoke.py (using unittest.mock to patch subprocess.run and urllib.request.urlopen):
  - test_cli_dispatch_default_backend: backend=None uses DEFAULT_BACKEND, calls subprocess with "claude" binary
  - test_cli_dispatch_custom_command: backend with command="aicc" calls "aicc" binary
  - test_cli_dispatch_custom_model: backend with model="opus" passes --model opus
  - test_api_dispatch_openai: mock urlopen, verify Authorization Bearer header, openai body shape, response content extraction from choices[0].message.content
  - test_api_dispatch_anthropic: mock urlopen, verify x-api-key header, anthropic body shape, response content extraction from content[0].text
  - test_api_dispatch_missing_key: api backend with unset api_key_env raises LLMInvokeError naming the var
  - test_api_dispatch_http_error: mock HTTPError, verify LLMInvokeError includes status code
  - test_api_dispatch_timeout: mock URLError with timeout message, verify LLMInvokeError
  - test_unsupported_backend_type: BackendConfig(type="unknown", ...) raises LLMInvokeError

  Existing tests calling llm_invoke(prompt) with no kwargs are preserved. Tests passing model= must be migrated to backend=BackendConfig(...) -- this is a deliberate signature change. They call `llm_invoke(prompt)` with no backend arg, which now resolves to DEFAULT_BACKEND -> cli path -> subprocess. The mock patches on subprocess.run should continue to work.
