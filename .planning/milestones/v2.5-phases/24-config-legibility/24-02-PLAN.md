## Tasks

### Task 1: Wire `code-forge init` to write gate.schema.json

**Files:**
- `src/code_forge/cli.py`
- `pyproject.toml`

**What:**

In the `elif args.subcommand == 'init':` block (cli.py line 1076), after
line 1088 `gate_path.write_text(GATE_YAML_TEMPLATE)`, add logic to write
gate.schema.json into the same .code-forge/ directory:

1. Read the bundled schema using `importlib.resources`:
   `importlib.resources.files('code_forge').joinpath('gate.schema.json').read_text(encoding='utf-8')`
   This works from both wheel install and editable install (setuptools>=68 +
   Python 3.12+ is verified in pyproject.toml). The project already uses
   importlib.resources (cli.py:1977 sets precedent).

2. Write to `gate_dir / "gate.schema.json"`. Apply the same --force guard
   as gate.yaml: skip if file exists and --force is not set. Print
   `"Created %s" % schema_path` to stderr on write.

3. In pyproject.toml `[tool.setuptools.package-data]`: the section exists
   (buildBackend is setuptools, per pyproject.toml line 5-6; verify with
   `grep -n "tool.setuptools.package-data" pyproject.toml`). The section
   currently has `"code_forge" = ["skills/**/*", "skills/**/.gitkeep", "rules/**/*"]`.
   If present: append `"gate.schema.json"` to that list (exact string match, not glob).
   New value: `["skills/**/*", "skills/**/.gitkeep", "rules/**/*", "gate.schema.json"]`
   If absent (create-if-missing): create the section with exactly:
   `[tool.setuptools.package-data]`
   `"code_forge" = ["skills/**/*", "skills/**/.gitkeep", "rules/**/*", "gate.schema.json"]`

4. Add `jsonschema>=4.18` to `[project.optional-dependencies].dev` in pyproject.toml.
   4.18+ is required: it ships the `referencing` package that Draft202012Validator
   depends on (earlier 4.x versions lack it, causing ModuleNotFoundError). E3
   verification and the entire 24-03 corpus test fail without this.
   If `[project.optional-dependencies].dev` exists: append `"jsonschema>=4.18"` to
   the dev list (alongside pytest, mutmut, semgrep).
   If absent (create-if-missing): create with `dev = ["jsonschema>=4.18"]`, then
   grep pyproject.toml for any existing dev deps and merge them into the list.

**Verify (smoke test):**

Prerequisite: run `pip install -e ".[dev]"` from the worktree root so
`importlib.resources.files('code_forge')` resolves to the worktree src AND
dev dependencies (including jsonschema>=4.18) are installed.
Verify: `python3 -c "import code_forge; print(code_forge.__file__)"` must
print a path inside `.worktrees/onboarding-step1/src/`.

```bash
pip install -e ".[dev]" -q
python3 -c "
import subprocess, tempfile, pathlib, json
tmp = pathlib.Path(tempfile.mkdtemp())
r = subprocess.run(
    ['code-forge', 'init'],
    cwd=str(tmp), capture_output=True, text=True
)
assert r.returncode == 0, 'init failed:\n' + r.stderr
assert (tmp / '.code-forge/gate.yaml').exists(), 'gate.yaml not written'
assert (tmp / '.code-forge/gate.schema.json').exists(), 'gate.schema.json not written'
schema = json.loads((tmp / '.code-forge/gate.schema.json').read_text())
assert 'properties' in schema, 'schema missing top-level properties'
assert 'backends' in schema['properties'], 'schema missing backends'
print('init writes both files -- PASS')
# Run 2: inject sentinels into BOTH files, then re-run init without --force.
# Content-equality alone cannot prove files were not touched (content is deterministic;
# overwrite + identical content = false pass). Use unique sentinels instead.
schema_sentinel = '{"_sentinel": "schema-do-not-overwrite"}'
yaml_sentinel = '_sentinel: yaml-do-not-overwrite\n'
(tmp / '.code-forge/gate.schema.json').write_text(schema_sentinel)
(tmp / '.code-forge/gate.yaml').write_text(yaml_sentinel)
r2 = subprocess.run(
    ['code-forge', 'init'],
    cwd=str(tmp), capture_output=True, text=True
)
# cli.py exits with EXIT_CLI_ERROR (2) when gate.yaml exists without --force,
# before reaching the schema-write code. Both sentinels must be preserved.
assert r2.returncode != 0, 'expected non-zero exit when gate.yaml exists: ' + r2.stderr
assert (tmp / '.code-forge/gate.schema.json').read_text() == schema_sentinel, \
    '--force guard broken: gate.schema.json was overwritten despite file existing'
assert (tmp / '.code-forge/gate.yaml').read_text() == yaml_sentinel, \
    '--force guard broken: gate.yaml was overwritten despite file existing'
print('--force guard: second init exits early, both sentinels preserved -- PASS')
"
```
