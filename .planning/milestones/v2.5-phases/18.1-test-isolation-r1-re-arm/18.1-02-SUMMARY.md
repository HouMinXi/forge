# Plan 18.1-02 Summary: Non-Code Carve-out + R1 Re-arm

## What was built

Added a non-code carve-out to the generated pre-commit hook, then re-armed
R1 with end-to-end integration tests. Depends on Plan 01 (isolation) landing
first -- the armed hook runs the full suite on code commits, so the suite
must be safe before arming.

1. **Non-code carve-out in `generate_hook_content()`** (`src/code_forge/install_hooks.py`):
   - Inverted whitelist (`NON_CODE`): `\.md$|\.txt$|\.yaml$|\.yml$|\.json$|\.toml$|...`
   - Shell logic: `NON_MATCH=$(echo "$STAGED" | grep -vE "$NON_CODE")`; if empty, exit 0
   - Carve-out placed BEFORE attestation -- non-code commits have zero receipts and
     would fail attestation if the carve-out ran after it
   - Unknown extensions do NOT match `NON_CODE`, so they trigger verify (safe default)
   - Present in both chain and no-chain hook variants

2. **`tests/test_hook_carveout.py`** (8 tests):
   - `test_carveout_block_present`: hook content contains `NON_CODE`
   - `test_docs_only_skips_verify`: docs-only staged commit exits 0 with stub code-forge
   - `test_code_file_triggers_verify`: .py staged file fails (stub gate-check exits 1)
   - `test_mixed_commit_triggers_verify`: code + docs mix triggers gate
   - `test_carveout_before_attestation`: `NON_CODE` index < `code-forge verify` index
   - `test_carveout_with_chain`: carve-out present with chain_path
   - `test_unknown_extension_triggers_verify`: .xyz file triggers verify (D-08)
   - `test_noncode_commit_without_stub` (SC 3 anti-mock guard): carve-out exits 0
     before reaching a nonexistent binary -- catches ordering bugs that stub tests miss

3. **`tests/test_r1_e2e.py`** (5 tests):
   - `test_install_hooks_succeeds_clean_repo`: EXIT_PASS, hook exists, executable
   - `test_r1_code_commit_triggers_gate`: .py commit fails (stub gate-check)
   - `test_r1_noncode_commit_passes`: .md commit succeeds (carve-out + stub verify=0)
   - `test_hooks_dir_no_stale_artifacts`: only pre-commit + commit-msg in hooks/
   - `test_existing_prepush_survives_install`: pre-push hook content unchanged after install

4. **README.md** (`7e4c110`): updated non-code commit guidance (carve-out, not --no-verify)
