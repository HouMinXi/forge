<objective>
Isolate the forge test suite from the real repo's .git directory and add a regression
guard that fails loudly if any test modifies real .git state.

Purpose: The 2026-06-11 incident showed that tests writing git config (core.hooksPath,
user.name, user.email) can leak to the real repo when tmp_path isolation fails. This plan
adds GIT_CEILING_DIRECTORIES as a session-wide env barrier, hardens test_install_hooks.py
with explicit per-test env, and installs a sessionstart/sessionfinish regression guard
that snapshots .git state and calls sys.exit(1) with a diagnostic diff on any drift.

Output: Modified tests/conftest.py with ceiling fixture + regression guard,
modified tests/test_install_hooks.py with per-test isolation.
</objective>

  <action>
  Per D-03/D-04/D-05, add pytest_sessionstart and pytest_sessionfinish hooks
  directly in tests/conftest.py. These act as a regression guard: snapshot .git
  state before any tests run, compare after all tests complete, and call
  sys.exit(1) with a diagnostic diff if anything changed.

  Implementation in conftest.py (add after the fixtures):

  1. pytest_sessionstart(session):
     a. Compute repo_root = Path(__file__).resolve().parent.parent
     b. Resolve the actual git directory using subprocess.run(
          ["git", "rev-parse", "--absolute-git-dir"], cwd=str(repo_root),
          capture_output=True, text=True).stdout.strip().
        Do NOT hardcode repo_root / ".git" -- in a worktree, .git is a FILE
        containing "gitdir: /path/to/real/.git/worktrees/name", not a directory.
        Using --absolute-git-dir handles both cases correctly.
        Set git_dir = Path(resolved_path).
     c. Snapshot the following into session.config.stash[_git_snapshot_key] (use
        pytest's stash API for forward compatibility with pytest 7+; define
        _git_snapshot_key = pytest.StashKey[dict]() at module level):
        - "config": output of subprocess.run(["git", "config", "--list", "--local"],
          cwd=str(repo_root), capture_output=True, text=True).stdout
        - "hooks": a sorted list of filenames in git_dir / "hooks" (if dir exists),
          filtering out .sample files. Also hash each hook file's content
          (hashlib.sha256) so content changes are detected, not just file presence.
        - "refs_heads": output of subprocess.run(
          ["git", "for-each-ref", "refs/heads/", "--format=%(refname) %(objectname)"],
          cwd=str(repo_root), capture_output=True, text=True).stdout
        - "HEAD": output of subprocess.run(["git", "rev-parse", "HEAD"],
          cwd=str(repo_root), capture_output=True, text=True).stdout.strip()
        - "dotfiles": sorted list of git-managed dotfiles in repo_root (e.g.,
          .gitignore, .gitattributes) with sha256 hashes. Use
          repo_root.glob(".git*") to match only git-related dotfiles (not
          .coverage, .venv, .pytest_cache, .ruff_cache, etc. which are
          transient build/test artifacts that change every run). Exclude
          .git itself (it's a directory or worktree file, not a tracked
          dotfile). Per D-04 requirement.

  2. pytest_sessionfinish(session, exitstatus):
     a. Re-capture the same five snapshots using identical commands.
     b. Compare each field. For any difference, build a diagnostic message:
        "FATAL: Test suite modified real .git state!" followed by per-field diffs:
        "Changed: .git/config\n  - {before_line}\n  + {after_line}" for each
        differing line.
     c. If ANY drift detected, write the diagnostic to sys.stderr via
        sys.stderr.write(diagnostic_msg + "\n"), then call sys.exit(1).
        Do NOT use pytest.fail() here -- pytest swallows the Failed exception's
        message when raised inside pytest_sessionfinish (the message is discarded
        by the outer except handler in _pytest.main.wrap_session). sys.exit(1)
        raises SystemExit which IS caught by the inner exit.Exception handler,
        preserving both the exit code and the stderr output.
     d. If no drift, do nothing (silent success).

  Per D-04, the guard checks: .git/config (config drift), .git/hooks/ directory
  contents (stub hook injection), refs/heads/ branch refs (fixture commits on
  live branches), and HEAD pointer (unexpected commit).

  Per D-05, drift = sys.stderr.write() + sys.exit(1) with diagnostic diff,
  not a warning. (Do NOT use pytest.fail() in sessionfinish -- message is
  swallowed by pytest internals.)

  Import subprocess, sys, hashlib, and difflib at the top of conftest.py
  (Path already imported from Task 1). Use difflib.unified_diff() to generate
  before/after diffs for multi-line snapshot comparisons (config, refs).
  IMPORTANT: unified_diff expects sequences of lines, not raw strings. Split
