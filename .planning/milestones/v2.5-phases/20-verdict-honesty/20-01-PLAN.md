AxisRunner Protocol (advisory, never blocking), makes a single LLM call with

the RuntimeRunner's evidence checking. TDD: tests are written first to lock
the AxisRunner contract, receipt schema, and advisory-never-blocks invariant.

    1. Create src/code_forge/runtime.py with:
       - RUNTIME_LIFECYCLE_QUESTION module-level constant (D-05): fixed question asking
         about runtime surfaces, lifecycle/side-effect risks, and smoke test needs.
         Includes {diff_text} format slot. Requests JSON response with "surfaces" and
         "findings" keys. Exact wording is Claude's discretion; must contain the three
         enumerated question parts and the JSON schema instruction.
       - write_smoke_receipt(receipts_dir, diff_text, surface, command, exit_code,
         transcript, timestamp): writes smoke-receipt-{surface}.json using tmp+replace
         atomic pattern from receipt.py. Fields: diff_sha256 (via compute_source_hash),
         surface, command (string), exit_code (int), transcript_sha256 (sha256 of
         transcript bytes), timestamp (ISO 8601 UTC), status (VERIFIED if exit_code==0
         else FAILED). Per D-01/D-07.
       - read_smoke_receipts(receipts_dir): reads all smoke-receipt-*.json files, returns
         list of dicts. Returns [] if dir missing or empty. Per D-07.
       - RuntimeRunner class implementing AxisRunner Protocol:
         __init__(self, backend=None): stores backend, initializes source_files=None,
         infra_errors=[]. is_advisory property returns True.
         run(self, diff_text, repo_root) -> list[AdvisoryFinding]:
           (a) Guard: empty diff -> return [].
           (b) Compute diff hash via compute_source_hash(git_diff=diff_text).
           (c) LLM call: build prompt via RUNTIME_LIFECYCLE_QUESTION.replace("{diff_text}",
               diff_text) (NOT str.format -- diffs containing { or } would KeyError).
               Invoke via llm_invoke(prompt, backend=self._backend). On LLMInvokeError:
               append to infra_errors, return [AdvisoryFinding with id="runtime-skipped",
               axis="RUNTIME", description containing error reason] (D-04 never-silent-skip).
           (d) Parse JSON from LLM response: extract "surfaces" list and "findings" list.
               On JSON parse error: append to infra_errors, return [AdvisoryFinding with
               id="runtime-skipped", axis="RUNTIME", description containing parse error]
               (D-04 never-silent-skip -- same treatment as LLMInvokeError).
           (e) Read smoke receipts from repo_root/.code-forge/smoke-receipts/.
           (f) Validate each receipt: diff_sha256 must match current diff hash; status
               must be "VERIFIED". Invalid receipts are discarded.
           (g) Compute NOT VERIFIED: case-insensitive substring containment between
               LLM-enumerated surfaces and receipt-declared surfaces. A surface is
               VERIFIED if any valid receipt's surface field contains or is contained
               by the LLM surface string (either direction). D-11 per-surface accounting.
           (h) Build AdvisoryFinding list: one finding per LLM-reported finding (from
               "findings" key) with axis="RUNTIME". When total surfaces > 0, add a
               summary finding with id="runtime-smoke-summary" and description:
               "smoke: {verified}/{total} surfaces verified; NOT VERIFIED: [{csv}]"
               (or "smoke: all {total} surfaces verified" when all verified).
               When total surfaces == 0 (LLM enumerated none), do NOT create the
               summary finding -- Plan 02 _display_smoke_status falls into case (c)
               and prints "smoke: no runtime surfaces detected" (GM-R5-L2 fix).
               Cross-plan contract: Plan 02 _display_smoke_status parses findings
               with id="runtime-smoke-summary" to extract the display text.
               Each VERIFIED surface includes its receipt diff_sha256[:8] fingerprint
               (D-09: "VERIFIED with receipt fingerprint").

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM response -> RuntimeRunner | LLM output is untrusted JSON; must handle malformed/missing keys |
| Smoke receipt file -> RuntimeRunner | Receipt on disk could be stale (TOCTOU) or hand-edited |
| --surface CLI arg -> receipt file | User-supplied surface name stored as data, never executed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-01 | Tampering | smoke receipt files | mitigate | Receipt keyed by diff content-hash (compute_source_hash); RuntimeRunner re-validates hash at read time; mismatch = discard |
| T-20-02 | Tampering | --surface argument | mitigate | Surface name stored as JSON string data only; never interpolated into shell commands or executed |
| T-20-03 | Spoofing | LLM response JSON | mitigate | JSON parse with try/except; missing keys produce empty results + infra_error; malformed data never treated as valid findings |
| T-20-04 | Information Disclosure | transcript in receipt | accept | Transcript is sha256-hashed, not stored verbatim; command string is stored but is user's own command |
| T-20-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this phase |
</threat_model>
