    **A. Create src/code_forge/graph_triage.py:**

    Module docstring: "GraphTriageRunner advisory axis: system-level blast-radius ranking. Implements REVIEW-SYSTEM-01."

    Imports: from __future__ import annotations, dataclasses (for field defaults), json, logging, os, pathlib.Path, shutil, sqlite3, subprocess, typing.Optional. From code_forge.advisory import AdvisoryFinding.

    Constants:
    - _SEM_TIMEOUT_S = 15 (per RESEARCH risk table: 15s timeout per entity)
    - _TOP_N = 10 (per D-03a: fixed top 10)
    - _UNNAMED_ENTITIES = frozenset({"module-level"}) (entities to skip)
    - _UNNAMED_PREFIX = "lines " (entity names starting with this are unnamed)

    Helper function _detect_backend(repo_root, gate_config) -> tuple[str, str] or None:
    1. If gate_config has graph_triage.enabled == False: return None.
    2. Check shutil.which("sem"): if found, return ("sem", path_str).
    3. Check gate_config graph_triage.db_path: if exists, return ("graphdb", path).
    4. Check repo_root / ".code-review-graph" / "graph.db": if exists, return ("graphdb", path).
    5. Check os.environ.get("CRG_DB_PATH"): if set and exists, return ("graphdb", path).
    6. Return None.

    Helper function _run_sem(diff_text, repo_root) -> list[dict]:
    Use sem diff --patch to analyze the exact diff forge is reviewing (not
    HEAD~1 which may diverge from staged/PR diffs). Write diff_text to a
    tempfile, then run subprocess.run(["sem", "diff", "--patch", "--format",
    "json"], stdin=f, capture_output=True, text=True,
    cwd=str(repo_root), timeout=30) inside a `with open(tmpfile) as f:` block
    (context manager prevents file handle leak). Parse stdout as JSON. Return list of
    change dicts from result["changes"]. On subprocess errors or JSON parse
    errors, return []. Clean up tempfile in finally block.

    Helper function _get_sem_impact(entity_name, file_path, repo_root) -> dict:
    Run subprocess.run(["sem", "impact", entity_name, "--file", file_path, "--json"], capture_output=True, text=True, cwd=str(repo_root), timeout=_SEM_TIMEOUT_S). Parse JSON. Return parsed dict. On TimeoutExpired or other errors, return {"impact": {"total": 0}, "dependents": []}.

    Helper function _run_graphdb(db_path, diff_files) -> list[dict]:
    Connect via sqlite3.connect(f"file:{db_path}?mode=ro", uri=True).
    For each file in diff_files, query nodes WHERE file_path LIKE '%' + file.
    For each node, count dependents via disambiguation SQL:
      SELECT DISTINCT c.source_qualified FROM edges c
      WHERE c.kind = 'CALLS' AND c.target_qualified = :entity_name
        AND EXISTS (SELECT 1 FROM edges i
                    WHERE i.kind = 'IMPORTS_FROM'
                      AND i.source_qualified LIKE substr(c.source_qualified, 1, instr(c.source_qualified, '::') - 1) || '%'
                      AND (i.target_qualified LIKE '%' || :module_name || '%'
                           OR i.target_qualified LIKE '%' || :entity_name || '%'))
    where module_name = file stem without .py extension.
    CAVEAT (from RESEARCH smoke test): this reduces false positives ~89%
    but does not eliminate them for common names (run, __init__). Findings
    from graphdb backend carry attribution="graph.db (degraded)".
    Return list of dicts: name, file, qualified_name, dependent_count,
    top_dependents (up to 5). Close connection in finally block.

    Helper function _parse_diff_files(diff_text) -> list[str]:
    Extract file paths from unified diff "+++ b/..." lines. Return unique paths without the "b/" prefix.

    Helper function _build_findings(ranked_entities, backend_name) -> list[AdvisoryFinding]:
    For each entity in ranked_entities (up to _TOP_N): create AdvisoryFinding with id="graph-triage-N" (N=1-based index), axis="GRAPH-TRIAGE", file=entity file, line_range=[entity start_line, entity end_line] if available else [0, 0], description formatted as "entity_name (impact: N downstream) -- top dependents: dep1, dep2, dep3", attribution="sem" or "graph.db (degraded)" depending on backend.

    No _build_skipped_finding helper. Tool-absent = return [] + infra_errors
    (same pattern as TaintRunner: print message to stderr, append to
    self.infra_errors, return empty list).

    Public function find_entity_dependents(entity_name, file_path, repo_root) -> list[str]:
    Detect available backend (sem preferred). If sem: run sem impact and return list of dependent entity IDs from impact.dependents. If graphdb: query edges for dependents of entity matching name+file. If neither: return []. Exported for future axes that need entity-level dependent lookup.

    Class GraphTriageRunner:
    - __init__(self): self.source_files (Optional[list[Path]], default None), self.infra_errors (list[str], default []), self._cached_findings (Optional[list[AdvisoryFinding]], default None).
    - is_advisory property: returns True.
    - run(self, diff_text, repo_root) -> list[AdvisoryFinding]:
      1. Clear infra_errors. If self._cached_findings is not None, return self._cached_findings (pre-loop cache hit, avoids redundant subprocess calls). Return [] for empty/whitespace diff.
      2. Load gate config: try loading repo_root / ".code-forge" / "gate.yaml" via gate_check.load_gate_config. Catch FileNotFoundError/ValueError -> gate_config = {}.
      3. Call _detect_backend(repo_root, gate_config). If None and gate.yaml has graph_triage.enabled=False: return [] (explicit disable). If None and no explicit disable: record loud-fail in infra_errors ("GraphTriageRunner: neither sem CLI nor graph.db found; install sem (https://github.com/Ataraxy-Labs/sem) or build code-review-graph"), print msg to stderr, return [].
      4. If backend is "sem": call _run_sem(diff_text, repo_root) to get changed entities. Filter out unnamed entities. For each named entity, call _get_sem_impact. Build ranked list sorted by impact.total descending.
      5. If backend is "graphdb": parse diff files. Call _run_graphdb. Sort by dependent_count descending.
      6. Call _build_findings with top _TOP_N entities and backend name. Return findings.
