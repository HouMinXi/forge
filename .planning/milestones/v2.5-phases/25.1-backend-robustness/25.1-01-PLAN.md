<objective>
Implement D-1 timeout circuit breaker: consecutive L1 timeouts abort the review
with exit code 6 instead of looping indefinitely.

Purpose: On slow backends (cross-Pacific CN models), forge runs cycle after cycle
of timeouts, never converging. The circuit breaker detects 5 consecutive L1
timeouts and aborts with an actionable error message, cutting the infinite loop.

Output: Modified llm_invoke.py, state.py, exit_codes.py, __init__.py,
factories.py, machine.py, cli.py + updated/new tests.

- LLMInvokeError.is_timeout: bool (llm_invoke.py) -- consumed by factories.py

- TimeoutCircuitBreaker class (machine.py) -- created at call site (cli.py, cross_repo.py), injected into build_l1_provider
- TimeoutBreaker(Exception) (machine.py) -- raised by TimeoutCircuitBreaker.record_timeout, caught by cli.py
