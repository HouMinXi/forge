<objective>
Upgrade _fixpoint_reached and the _run_local reset step from binary (any finding
= reset) to severity-tiered (P0/P1 = full reset, P2 = restart current cycle
without counter reset, P3 = density check per SKILL.md thresholds).

Purpose: A steady stream of P2 findings (style, minor) resets the counter every
round under the binary rule, so the machine never converges. The SKILL.md tiered
rule (already documented and reviewed) is the intended evolution. This plan lands
it in machine.py so both the StateMachine and SKILL.md follow the same rule.

Output: machine.py _fixpoint_reached and _run_local updated; regression tests added.

NOTE: P3 density thresholds come from flow_contract.py (created in plan 04, which
this plan depends on). Import from flow_contract.py, do NOT hardcode the values.
The values recorded in SKILL.md (lines 289-299) are:
  distinct_per_file > 5   -> P2-equivalent restart
  distinct_per_diff > 10  -> P2-equivalent restart
  density > 0.15/line     -> P2-equivalent restart
</objective>

    _fixpoint_reached() -> _FixpointResult (replaces binary bool version):
      Step 0 (PRESERVED -- old clauses (a) and (b), fire before tiering):
        Compare current CONFIRMED findings against prior round's dispositions.

      Step 4: if any CONFIRMED: determine tier of each CONFIRMED finding

        - if any P2 (no P0/P1): return CYCLE_RESTART

          else return CLEAN (P3 below threshold = clean for counter purposes)
