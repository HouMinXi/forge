<objective>
Create flow_contract.py as the single source of truth for the flow contract constants
(P3 thresholds, default clean round threshold). Machine.py imports from it instead of
hardcoding. A drift guard test parses SKILL.md and fails when SKILL.md's prose
thresholds disagree with the constants -- preventing re-divergence.

Purpose: The reset rule drifted between machine.py (binary) and SKILL.md (tiered)
precisely because the rule was written in two places independently. flow_contract.py
ensures any future edit to thresholds must change one file; the drift test then catches
any SKILL.md update that forgets to sync.

D5 mechanism chosen: constants module (flow_contract.py) + prose-parsing drift test.
Rejected alternatives:
  - "Generated SKILL.md section" -- SKILL.md is human-maintained prose; generation
    would overwrite human edits on every sync.
  - "Runtime SKILL.md reader in machine.py" -- machine.py must not depend on a skills
    file at runtime; skills are session-layer artifacts.

Output:
  - src/code_forge/flow_contract.py: four exported constants
  - src/code_forge/machine.py: P3 branch imports from flow_contract (not hardcoded)
  - tests/test_flow_contract_drift.py: drift guard + contract freeze test
  - skills/code-forge/SKILL.md: add one-line "canonical source: flow_contract.py" note
    at the P3 threshold section (lines 289-299) so humans know where to sync
</objective>
