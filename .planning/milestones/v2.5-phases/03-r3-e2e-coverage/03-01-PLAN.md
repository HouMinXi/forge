    1. Signature-pattern table (module constant), Python + shell only for now:
       - Python: a regex matching a def line, e.g. r"^\s*(async\s+)?def\s+\w+\s*\("
         and return-type arrow r"->\s*\S+\s*:".
       - shell: a regex matching a function definition, e.g.
         r"^\s*(function\s+)?[A-Za-z_]\w*\s*\(\s*\)\s*\{?".
       Group these as a dict {lang: [compiled regexes]} or a flat list of
       compiled patterns (executor's choice). Add a SECTION_HEADER_DEF_RE that
       matches a def-pattern inside a section_header string (the enclosing
       function git emits, e.g. "@@ ... @@ def parse(...)" -> section_header is
       "def parse(...)"). The C-style shape (return type BEFORE the name, no
       "->") is documented in CONTEXT.md D-02a but NOT shipped here -- Python +
       shell only (a wrong C pattern silently misses changes; add it with its
       own test when a real C consumer appears).

    2. detect_signature_changes(diff_text: str) -> set[str]:
       Parse diff_text with unidiff.PatchSet (wrap in try/except
       unidiff.errors.UnidiffParseError -> return empty set, never raise).
       For each patched_file (skip is_removed_file), for each hunk:
         - Arm 1 (added-lines regex): if any line with line.is_added has
           line.value matching any signature pattern -> add patched_file.path.
         - Arm 2 (section_header): if hunk.section_header is truthy AND
           SECTION_HEADER_DEF_RE matches it -> add patched_file.path.
       The two arms are a UNION. When section_header is empty (flat shell with
       no function wrapper), only Arm 1 contributes -- this is the documented
       fallback, not an error. Return the set of file paths.

    3. group_source_files(files: list[str], components: dict | None = None,
                          exclude_test_dirs: bool = True) -> dict[str, list[str]]:
       - If exclude_test_dirs: drop any file whose first path segment is in
         {"tests", "test", "spec"} (fixed builtin set per D-02b).
       - If components is None (default mode): group remaining files by first
         path segment (the part before the first "/"). A top-level file with
         no "/" groups under its OWN filename (e.g. "setup.py" -> group key
         "setup.py"). This rule is LOCKED -- do NOT use "" as a group key, as
         that would silently collapse all top-level files into a single
         pseudo-group and could falsely trigger Layer 1 when a top-level file
         is co-changed with one src/ file.
       - If components is provided (a dict component_name -> list_of_path_globs,
         the shape Plan 02 will load from components.yaml): assign each file to
         the first component whose globs match (fnmatch). Files matching no
         component are grouped under their first path segment as a fallback.
       - Return {group_name: sorted(list_of_files)} (omit empty groups).

    4. check_layer_2(diff_text: str, repo_root: Path,
                     components: dict | None = None) -> list[StateFinding]:
       STUB in this plan. Return []. (Plan 02 implements the components.yaml
       loader + co-occurrence trigger here.) Keep the signature stable so
       Plan 02 fills the body without changing callers.

    5. check_layer_1(diff_text: str, components: dict | None = None)
                     -> list[StateFinding]:
       - sig_files = detect_signature_changes(diff_text). If empty -> return []
         (no signature change means no Layer 1 nudge).
       - changed = get_changed_files(diff_text) (reuse diff.py).
       - groups = group_source_files(changed, components).
       - If len(groups) < 2 -> return [] (not cross-component).
       - If sig_files is disjoint from changed -> return [] (defensive; sig
         files should be a subset of changed).
       - Otherwise emit ONE finding:
           source="E2E_CHECK", disposition=Disposition.DISMISSED,
           id="e2e-layer1", file="" (spans multiple), line_range=[],
           fingerprint="e2e-l1:" + hashlib.sha256(
             ("|".join(sorted(groups.keys())) + "::" + "|".join(sorted(sig_files))).encode("utf-8")
           ).hexdigest()[:16]
             (CONTRACT: sha256 of the canonical "groups|sig_files" string,
             hex-truncated to 16 chars -- mirrors the L0/L1 fingerprint
             scheme so re-runs on the same diff dedup deterministically),
           description=a one-line nudge naming the >=2 groups and the
             signature-changed file(s): e.g. "cross-component change spans
             groups {A, B}; signature changed in {f}; is there an e2e test for
             the joined path?"
         Return [finding].
       Layer 1 is advisory (DISMISSED) and MUST NOT flip the verdict.

    6. run_e2e_check(diff_text: str, repo_root: Path)
                     -> tuple[list[StateFinding], list[str]]:
       Orchestrator. infra_errors = []. Wrap the body in try/except Exception
       (append str(e) to infra_errors, return ([], infra_errors)) so a
       malformed diff never crashes the review.
       - For THIS plan, components = None (the components.yaml loader is Plan
         02). l1 = check_layer_1(diff_text, components=None).

       - Return (l1 + l2, infra_errors).
       Plan 02 will load components.yaml inside run_e2e_check and pass it to
       both layers, then add Layer 1/Layer 2 dedup.

    (diff_text is provided by the caller via the git module in Plan 03).

    minor-version bump could remove or rename it without changing the

    detection would regress to false negatives).

    asserts `hasattr(hunk, 'section_header')`). The pin here is the
    defense-in-depth: even if a contributor bumps the lower bound,

    Do NOT change any other dependency in pyproject.toml.
