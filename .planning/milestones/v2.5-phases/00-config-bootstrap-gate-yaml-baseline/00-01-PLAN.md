3. Parse the output and generate .worktrees/phase-00/.forge/test_baseline.json. The schema
   must match RESEARCH Pattern 2 exactly:
   ```json
   {
     "schema_version": "1.0",
     "generated_at": "<ISO 8601 UTC timestamp>",
     "test_command": ["python3", "-m", "pytest", "tests/", "-q"],
     "total_tests": <actual count from the run>,
     "known_failures": [<list of test IDs that FAILED, empty if all pass>],
     "test_results": {
       "<pytest node ID>": "passed" or "failed",
       ...for every test...
     }
   }
   ```
   Use a short Python script to parse the verbose pytest output:
   - Lines matching pattern `<path>::<test> PASSED` -> "passed"
   - Lines matching pattern `<path>::<test> FAILED` -> "failed"
   - The test ID is everything before " PASSED" or " FAILED"
   Upgrade path: Phase 1 should use --junitxml for robust machine-readable
   output. This inline regex is sufficient for Phase 0's one-shot generation.

   Write the script inline (no new .py file -- this is a one-shot generation):
   ```python
   import json, re, sys
   from datetime import datetime, timezone

   with open("/tmp/pytest_baseline_run.txt") as f:
       lines = f.readlines()

   test_results = {}
   for line in lines:
       m = re.match(r'^(tests/\S+)\s+(PASSED|FAILED)', line)
       if m:
           test_id, status = m.group(1), m.group(2).lower()
           test_results[test_id] = status

   baseline = {
       "schema_version": "1.0",
       "generated_at": datetime.now(timezone.utc).isoformat(),
       "test_command": ["python3", "-m", "pytest", "tests/", "-q"],
       "total_tests": len(test_results),
       "known_failures": sorted(tid for tid, s in test_results.items() if s == "failed"),
       "test_results": dict(sorted(test_results.items())),
   }

   with open(".forge/test_baseline.json", "w") as f:
       json.dump(baseline, f, indent=2)

   print(f"Baseline: {baseline['total_tests']} tests, {len(baseline['known_failures'])} failures")
   ```
