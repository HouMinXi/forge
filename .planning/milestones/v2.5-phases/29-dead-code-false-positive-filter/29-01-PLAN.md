    5. _is_dead_python(file_path: str, line: int) -> bool per D-01: uses tree-sitter via tree_sitter_language_pack.get_parser("python"). Compile parser ONCE at module level (not per call). Uses _find_deepest_at_line helper to locate deepest node at target_line (0-indexed = line - 1). Walks ancestors upward looking for if_statement nodes. For each if_statement ancestor: (a) check that the target line is inside the CONSEQUENCE body (the if-block), NOT inside the ALTERNATIVE body (else-block) -- a line in the else-branch of `if TYPE_CHECKING:` is LIVE, not dead; (b) the block is dead if the condition text is in _DEAD_CONDITIONS frozenset {b"TYPE_CHECKING", b"False"} (unconditionally dead) OR it is a sys.version_info guard that EVALUATES to False on the running interpreter. For the version guard (FINDING-E (b) -- EVALUATE, do NOT blanket-flag any `<`): if condition_text contains b"sys.version_info" AND is a SIMPLE comparison (no b" and "/b" or " -- else fail-safe live per D-06), parse the operator (one of < <= > >= == !=) and the right-hand version tuple literal (regex + ast.literal_eval on the `(...)` group), then compute guard_true = _CMP[op](sys.version_info, parsed_tuple) using operator.{lt,le,gt,ge,eq,ne}; the block is dead iff guard_true is False. Any parse failure, non-tuple RHS, or compound condition returns False (live) per D-06. Rationale: a blanket "any `<` is dead" rule wrongly drops LIVE callers inside `if sys.version_info < (3, 13):` on Python 3.11/3.12 -- the one direction D-06 forbids. Returns True only if both (a) and (b) hold. Returns False on any OSError / parse failure per D-06.

    6. _find_deepest_at_line(node, target_line: int) helper: recursive descent through tree-sitter children; returns deepest node whose start_point[0] <= target_line <= end_point[0].

    7. _is_dead_c(file_path: str, line: int) -> bool per D-01: lexical scan. Read file lines, walk UPWARD from target line. Compiled regexes anchored to optional leading whitespace: _IF0_RE = re.compile(r'^\s*#\s*if\s+0\b'), _IF_RE = re.compile(r'^\s*#\s*if\b'), _ENDIF_RE = re.compile(r'^\s*#\s*endif\b'), _ELSE_RE = re.compile(r'^\s*#\s*(?:else|elif)\b'). Algorithm:
       depth = 0
       for i in range(line - 2, -1, -1):  # 0-indexed, walk up
           if _ENDIF_RE.match(lines[i]): depth += 1
           elif _ELSE_RE.match(lines[i]):
               if depth == 0: return False  # in #else/#elif branch of something -- conservatively live
           elif _IF0_RE.match(lines[i]):
               if depth == 0: return True   # unmatched #if 0 = dead
               depth -= 1
           elif _IF_RE.match(lines[i]):
               if depth == 0: return False  # live #if guard above us
               depth -= 1
       return False  # reached top without finding #if 0
    Returns False on OSError or IndexError per D-06. Known honest-ceiling limitation: #else branch of #if 0 is conservatively treated as live (the #else reset at depth==0 fires before reaching #if 0); nested preprocessor inside #if 0 blocks may also return False (miss-not-noise direction per D-06).

    8. _live_callers(cursor: sqlite3.Cursor, target_name: str, module_name: str) -> list[LiveCaller] per D-02, D-08: signature takes (target_name, module_name) so the function owns the SQL extraction per D-08 -- a deliberate D-02+D-08 merge, now reflected in D-02 itself.
