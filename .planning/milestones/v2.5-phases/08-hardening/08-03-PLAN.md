## Quick Start

### Basic Usage (Terminal)

Default uses claude CLI with your default model:
```bash
code-forge review
```

Override model for this run:
```bash
FORGE_LLM_MODEL=claude-opus-4-5 code-forge review
```

Use a configured API backend:
```bash
FORGE_BACKEND=claude-api code-forge review
```

### Environment Variables

Most common configuration:

- **FORGE_BACKEND**: Backend to use (default: session-default which is claude -p)
- **FORGE_OUTLET**: Force outlet selection (cli or inline; auto-selects if unset)
- **FORGE_LLM_MODEL**: Model override for cli backends (e.g. claude-opus-4-5)

For full configuration reference including backends.yaml format and auth setup, see docs/configuration.md.

### Editor Integration

To use code-forge from VS Code, Cursor, or PyCharm, set environment variables so the editor terminal can find your API keys:

- VS Code Setup: docs/setup-vscode.md
- Cursor Setup: docs/setup-cursor.md
- PyCharm Setup: docs/setup-pycharm.md

Place after "Installation" section if it exists, otherwise after initial description.
