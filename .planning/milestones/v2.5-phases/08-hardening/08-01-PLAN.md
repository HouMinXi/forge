|----------|-------------|

| Python → HTTP API | User-controlled prompt in HTTP body; API key from env must not leak |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Tampering | subprocess command construction | mitigate | Use list-form cmd (no shell=True), shlex.quote for file paths |
| T-08-02 | Information Disclosure | API key in env | mitigate | api_key_env lookup at call time, never log/print api_key value |
| T-08-03 | Denial of Service | orphan subprocess accumulation | mitigate | Process group cleanup via _kill_tree + signal handlers (CLI-07) |
| T-08-04 | Elevation of Privilege | signal handler race | accept | Python signal handlers run between bytecodes; os.killpg is signal-safe |

</threat_model>
