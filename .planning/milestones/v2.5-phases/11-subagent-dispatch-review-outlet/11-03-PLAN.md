<objective>
Implement the subagent-dispatch review outlet (SC#1, SC#4 of BACKEND-02).

Purpose: Add "subagent" as a third outlet type. When selected, SKILL.md directs the
session model to spawn one fresh Agent per review pass (Pass 1, Pass 2, Pass 3). Each
Agent gets a fresh context window, providing the same anti-fabrication guarantee as
the CLI subprocess outlet (Outlet A) but without cold-start latency or API key
requirements. On any Agent error, SKILL.md reports the error and STOPs (fail-closed,
consistent with Outlet A behavior per SC#4).

This plan is GATED on Plan 11-02 (viability gate) returning PASS. If the viability
gate failed, this plan must NOT execute.
