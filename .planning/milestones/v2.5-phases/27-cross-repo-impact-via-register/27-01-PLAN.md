run() algorithm (exact order):
1. self.infra_errors.clear(); if cached return cache; if not diff_text.strip() return [].
2. primary_db = get_db_path(repo_root). If not exists -> infra_errors.append(
   "cross-repo-impact: primary graph.db not found; build code-review-graph") ; return [].
3. changed = resolve_changed_symbols(diff_text, primary_db). If empty -> return []
   (genuine no-impact; infra_errors stays EMPTY).
4. registry = Registry(path=_registry_path()); repos = registry.list_repos().
   siblings = [r for r in repos if Path(r["path"]).resolve() != repo_root.resolve()].
   If not siblings -> infra_errors.append("cross-repo-impact: no sibling repos
   registered; use code-review-graph register") ; return [].
5. hits = []; for sib in siblings:
     alias = sib.get("alias") or Path(sib["path"]).name
     sib_db = get_db_path(Path(sib["path"]))
     if not sib_db.exists(): infra_errors.append("cross-repo-impact: sibling '%s'
       graph.db missing" % alias); continue
     try: callers = find_cross_repo_callers(str(sib_db), changed)
     except (sqlite3.Error, OSError) as e:
       infra_errors.append("cross-repo-impact: sibling '%s' graph.db unreadable: %s"
         % (alias, e)); continue          # CLOSES the graph_triage silent-degrade gap
     for sym in changed:
       sym_callers = [c for c in callers if c["symbol"] == sym["name"]]
       hits.extend({**c, "alias": alias, "changed_file_path": sym["file_path"]}
                   for c in sym_callers)
6. rank hits by _subsystem_proximity(caller_file, hit["changed_file_path"]) desc
   (changed_file_path carried from resolve_changed_symbols); build AdvisoryFinding per hit:
     id="cross-repo-impact-%d" % (i+1), axis=_AXIS,
     file="%s:%s" % (alias, caller_file), line_range=[line or 0, line or 0],
     description="%s used by %s at %s:%d" % (symbol, alias, caller_file, line),
     attribution="cross-repo graph.db"
   cap _TOP_N; cache; return.

<threat_model>
## Trust Boundaries
- registry.json and each sibling repo path/graph.db are EXTERNAL inputs (the registry is
  user/tool-written). Treat sibling db as untrusted: open read-only
  (sqlite3 file:...?mode=ro), wrap every access in try/except (sqlite3.Error, OSError),
  never write. A corrupt/hostile db must degrade to a SKIP infra_error, never crash and
  never silently pass (D-04 gap closure).
- alias and file paths flow into AdvisoryFinding.file as display strings only; they are
  never used to open files in this plan, so path-traversal in a relpath is inert here
  (note it for any future consumer that resolves the path).

## STRIDE Threat Register
- Tampering: a sibling db with a poisoned target_qualified could inject a misleading
  caller name -> contained: advisory only, never blocks; name shown is descriptive.
- DoS: a huge sibling db / many siblings -> bounded by per-symbol SQL + _TOP_N cap +
  the read-only single-pass query; no transitive chaining in v1 (D-07).
- Info disclosure: cross-repo finding reveals a sibling path/alias -> intended (the
  feature's purpose); no file contents are read, only graph.db metadata.
</threat_model>
