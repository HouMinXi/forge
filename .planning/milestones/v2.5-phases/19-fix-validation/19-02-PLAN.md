       d. If FixvalSkip: record a DISMISSED StateFinding with source="FIXVAL",

          Proceed to PASS verdict (skip is not a block).
       e. If FixvalCandidate: get test_cmd from gate.yaml (same pattern as _run_l2_phase),
          get commit_message from self._get_commit_message() (reads COMMIT_EDITMSG

          when FIXVAL did not validate), proceed to PASS verdict.

       The _finalize_local_terminal method currently just sets PASS + converged + persist.
       The FIXVAL gate runs BEFORE that final PASS assignment. If FIXVAL blocks,
       the method returns early with FAIL. If not, it falls through to the existing
       PASS logic.

       Add _get_commit_message private method:
       Uses `git rev-parse --git-path COMMIT_EDITMSG` to resolve the correct
       path (worktree-safe: in worktrees .git is a file, not a directory, so
       hardcoded `.git/COMMIT_EDITMSG` fails). Only reads COMMIT_EDITMSG when
       it exists (it may be stale from a previous commit if not in hook context).
       Falls back to git log -1 --format=%B for post-commit / CI scenarios.
       Returns empty string on any exception (with logger.warning for audit).
       ```
       result = subprocess.run(
           ["git", "rev-parse", "--git-path", "COMMIT_EDITMSG"],
           capture_output=True, text=True, cwd=self.cwd
       )
       if result.returncode == 0:
           path = Path(result.stdout.strip())
           if not path.is_absolute():
               path = self.cwd / path
           if path.exists():
               return path.read_text().strip()
       # fallback for post-commit / CI
       result = subprocess.run(["git", "log", "-1", "--format=%B"], ...)
       ```
