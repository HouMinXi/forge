    Add a new private function _merge_and_write:

    def _merge_and_write(result: DetectionResult, output_path: Path) -> None:
        """Merge detected tools into existing tools.yaml, preserving user entries.

        User-added entries (names not in any tool registry) are preserved.
        Detected entries update/overwrite stale entries of the same name.
        Falls back to fresh generation if existing file is empty or corrupt.
        """
        try:
            with open(output_path, "r", encoding="utf-8") as f:
                existing_data = yaml.safe_load(f)
        except (yaml.YAMLError, OSError, ValueError):
            existing_data = None

        if not existing_data or not isinstance((existing_data if isinstance(existing_data, dict) else {}).get("tools"), dict):
            generate_tools_yaml(result, output_path)
            return

        existing_tools = existing_data["tools"]

        # Build detected tools dict (same logic as generate_tools_yaml)
        detected_tools: dict[str, dict] = {}
        for tool_name in result.detected:
            meta = _get_tool_meta(tool_name)
            if meta and "tools_yaml_entry" in meta:
                detected_tools[tool_name] = copy.deepcopy(meta["tools_yaml_entry"])

        # Merge: existing entries preserved, detected entries update/add
        merged = dict(existing_tools)
        merged.update(detected_tools)

        output_path.parent.mkdir(parents=True, exist_ok=True)
        with open(output_path, "w", encoding="utf-8") as f:
            yaml.safe_dump({"tools": merged}, f, default_flow_style=False)

| Boundary | Description |
|----------|-------------|
| filesystem -> detect.py | Reads pyproject.toml, *.sh globs, existing tools.yaml -- all user-controlled input |
| detect.py -> tools.yaml | Writes tool config that controls what commands L0 runner executes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | Tampering | tools.yaml merge | mitigate | _merge_and_write uses yaml.safe_load (not yaml.load, no code execution); merged entries still pass through load_registry validation at review time before any command is executed; only the merge step tolerates unknown output_formats to preserve user entries |
| T-10-02 | Tampering | SHELL_TOOL_REGISTRY command | accept | Command value is a constant string "shellcheck -f json"; user cannot inject via detection; actual execution happens in runner.py which already handles untrusted command output |
| T-10-03 | Information Disclosure | glob scanning | accept | Globs only check file existence (*.sh, *.py) in project root + one level; no file content is read during detection |
| T-10-SC | Tampering | npm/pip/cargo installs | accept | No new package installs in this phase; all dependencies (pyyaml, copy stdlib) already present |
