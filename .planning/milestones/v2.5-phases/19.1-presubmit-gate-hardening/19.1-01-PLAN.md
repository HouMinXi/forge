    Write failing tests FIRST in tests/test_gate_check.py under a new class
    TestPresubmitValidation. Use the existing mock_open pattern for fs_open
    injection.

    Schema for a single presubmit entry (per D-01, D-02, D-09):
      command: list[str] -- REQUIRED. The linter command. Each element validated
        against SHELL_METACHARACTERS (WITHOUT KNOWN_RUNNERS check).
      applies_to: str -- REQUIRED. Glob pattern (e.g. "*.py"). Must NOT contain
        single-quote (') or double-quote (") -- these break generated shell quoting.
      on: str -- REQUIRED. One of "diff", "patch" ONLY. "message" is REJECTED with
        ValueError "on: message not yet supported -- would silently never execute;
        use diff or patch". This is fail-closed per D-09: accepting "message"
        creates a configured-but-never-running linter. Remove this restriction when
        message-mode execution is implemented.
      when_exists: str -- OPTIONAL. Path; activates only when path exists at repo
        root. Must NOT contain single-quote (') or double-quote (").

    Add validate_presubmit_entry(entry: dict) -> None (raises ValueError on bad
    entries) and validate_presubmit_command(command: list[str]) -> None (checks
    SHELL_METACHARACTERS, skips KNOWN_RUNNERS).

    Add fnmatch_to_grep(glob: str) -> str that converts glob patterns to POSIX ERE
    compatible with `grep -E`. Do NOT use fnmatch.translate() -- it produces
    Python-only constructs (`(?s:...)`, `\Z`) that grep -E cannot parse.
    Custom converter rules:
      `*` -> `.*`, `?` -> `.`, `.` -> `\.`, then wrap: `^<result>$`
      E.g.: "*.py" -> `^.*\.py$`, "test_*.py" -> `^test_.*\.py$`
    Store result in validated entry as "applies_to_grep" for direct shell use.
    Tests MUST use `subprocess.run(['grep', '-E', pattern])` (real grep, not
    Python re) to verify grep compatibility:
      - fnmatch_to_grep("*.py") matches "foo.py" via grep
      - fnmatch_to_grep("test_*.py") matches "test_foo.py" AND "test_.py"
        (note: * matches zero chars, test_.py is a valid match)
      - fnmatch_to_grep("*.py") does NOT match "foo.js" via grep

    Extend load_gate_config: after the existing test-section validation, add:

    1. Optional non_ascii field (top-level in gate.yaml, NOT inside presubmit entry):
       Values: "ai-smell" (default) | "strict". Unknown string -> raise ValueError
       (fail-closed). If absent, default is "ai-smell".
         validate: if "non_ascii" in data:
           if data["non_ascii"] not in ("ai-smell", "strict"):
             raise ValueError("non_ascii must be 'ai-smell' or 'strict', got: ...")
       Callers access: data.get("non_ascii", "ai-smell")

    2. Optional presubmit-section block. If "presubmit" key exists in data:
       - Must be a list
       - Each element validated via validate_presubmit_entry
    If "presubmit" is absent, that is valid (the section is optional).

    Return the full data dict as before.

    IMPORTANT: Do NOT add presubmit commands to KNOWN_RUNNERS. Presubmit linters
