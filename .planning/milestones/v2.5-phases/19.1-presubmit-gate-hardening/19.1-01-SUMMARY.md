## What Was Built

### gate_check.py additions

Three new functions:

**fnmatch_to_grep(glob: str) -> str**
Converts shell glob to POSIX ERE for grep -E. Custom converter (not
fnmatch.translate) avoids Python-only constructs. Rules: * -> .*, ? -> .,
. -> \., anchored ^...$. Verified via real subprocess grep in tests.

**validate_presubmit_command(command: list[str]) -> None**
Checks each command element against SHELL_METACHARACTERS. Does NOT check
KNOWN_RUNNERS -- presubmit linters are user-supplied external tools.

**validate_presubmit_entry(entry: dict) -> None**
Validates one presubmit list entry. Required: command (list, no metachars),
applies_to (string, no quotes), on (diff or patch). Optional: when_exists
(string, no quotes). Rejects on=message fail-closed. Normalizes YAML 1.1
boolean coercion of bare 'on:' key. Stores applies_to_grep in entry.

**load_gate_config extensions:**
- non_ascii field: accepts ai-smell or strict; unknown value raises ValueError
  (fail-closed); absent defaults to ai-smell.
- presubmit section: must be list if present; each entry validated via
  validate_presubmit_entry with index in error message.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] YAML 1.1 bare 'on:' key coercion**
- **Found during:** Task 1 GREEN phase
- **Issue:** YAML 1.1 treats bare on: as boolean True. A presubmit entry
  {on: diff} parses to {True: 'diff'}, causing validate_presubmit_entry
  to raise "missing required field 'on'" on valid config.
- **Fix:** Validator checks for both "on" (string) and True (YAML-coerced)
  keys, normalizes to "on" string key, then validates the value. Users can
  write unquoted on: diff in gate.yaml.
- **Files modified:** src/code_forge/gate_check.py
- **Commit:** 5ee6d93

**2. [Rule 3 - Blocking] fixval.py missing from worktree**
- **Found during:** Task 2
- **Issue:** test_fixval.py imports code_forge.fixval which was added to
  main after the worktree branched. Without it, pytest collection fails.
- **Fix:** Copied fixval.py from main via git show into the worktree src
  directory. Not committed as new work -- it already exists on main.
- **Impact:** Worktree-only; no merge conflict risk.
