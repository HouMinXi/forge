## Requirements (4 plan reqs + 5 integration responsibilities)

- **CLI-01**: argparse surface `forge [--mode local|ci] [--falsification-engine auto|stub|real] [--sandbox] [--baseline empty|<git-ref|pseudo>|<snapshot-path>] [--head <git-ref|pseudo>] [path...]`. Defaults match REQUIREMENTS line 75 (mode = TTY default; engine = auto; sandbox = off; baseline = HEAD git / empty non-git; head = WORKING git / ignored non-git).
- **CLI-02**: exit code map -- 0 PASS, 1 FAIL, 2 CLI_ERROR (argparse / registry parse / invalid args), 3 BUSY (ForgeLockBusy from 02-04 lock), 4 ESCALATED (Verdict.ESCALATED from 02-02 state machine). `forge --help` documents the map.
- **CLI-03**: environment overrides for `FORGE_MODE` (consumed by 02-04 resolve_mode), `FORGE_FALSIFICATION_ENGINE`, `FORGE_MAX_TOTAL_ROUNDS`, `FORGE_MAX_FIX_ATTEMPTS_PER_FINGERPRINT`. Precedence: CLI flag > env > default.
- **STATE-10**: Falsifier factory `--falsification-engine auto|stub|real`. `auto` = try import Phase 4 module, fall back to stub. `stub` = StubFalsifier with default disposition. `real` = Phase 4 falsifier (not shipped v2.0; explicit `real` raises with clear message pointing at Phase 4 not being implemented).
- **Integration responsibility 1 (revert_fn factory)** (R2-M2 update post-B1): build `revert_fn: Callable[[StateFinding], None]` for StateMachine constructor. Git mode -> `git restore <file>`. **Non-git mode -> revert_fn raises NotImplementedError (v2.0 limitation per B1: 02-03 Snapshot stores content_hash only, no raw content to restore). To prevent the NotImplementedError from crashing 02-02 (which does NOT wrap revert_fn in try/except), 02-05 also wraps the autofixer in non-git mode via `_NonGitSafeAutoFixer` so PARSE_FAIL is converted to NO_CHANGE before reaching revert_fn (R2-M1 fix).**
- **Integration responsibility 2 (HOLD-resume loop)**: when StateMachine returns `Verdict.PENDING`, invoke `run_hold_ui` (02-04), then re-construct StateMachine and re-run. Loop terminates on terminal verdict (PASS/FAIL/ESCALATED) or HoldAborted exception.
- **Integration responsibility 3 (lock lifecycle)**: acquire `.forge/forge.lock` at startup via ForgeLock context manager (02-04). Released on clean exit AND on SIGINT/SIGTERM (signal chaining done by 02-04). Lock conflict -> exit 3.
- **Integration responsibility 4 (BaselineSpec construction)**: parse `--baseline` + `--head` strings into `BaselineSpec` discriminated union (02-03). Validate against cwd (git repo? non-git?). Invalid combination -> exit 2.
- **Integration responsibility 5 (env override resolution)**: parse `FORGE_MAX_TOTAL_ROUNDS` + `FORGE_MAX_FIX_ATTEMPTS_PER_FINGERPRINT` as ints with bounds checking; pass to StateMachine constructor. Non-int env value -> exit 2.

```python
def main() -> int:
    """Entry point. Returns exit code (caller wraps sys.exit if needed).

    Single return path so tests can assert the integer rather than
    catching SystemExit. setuptools entry-point shim calls sys.exit(main()).
    """
    parser = _build_parser()
    try:
        args = parser.parse_args()
    except SystemExit as e:
        # argparse exits 2 on invalid args; preserve that contract.
        return int(e.code) if e.code is not None else EXIT_CLI_ERROR

    try:
        verdict = _run(args, env=os.environ, cwd=Path.cwd())
    except CliError as exc:
        print("forge: error: %s" % exc, file=sys.stderr)
        return EXIT_CLI_ERROR
    except ForgeLockBusy as exc:
        print("forge: %s" % exc, file=sys.stderr)
        return EXIT_BUSY
    except Exception as exc:  # noqa: BLE001 (R3-L2 top-level safety net)
        # R3-L2: any unhandled exception (Pattern B bug class blindness:
        # could be 02-XX product gap surfaced at integration). Exit FAIL=1
        # with traceback to stderr so operator can triage. Do NOT swallow.
        import traceback
        print("forge: unexpected error: %s" % exc, file=sys.stderr)
        traceback.print_exc(file=sys.stderr)
        return EXIT_FAIL

    # B2-FIX: PENDING is a non-terminal HOLD-pending state. HoldAborted
    # in _run_hold_loop bubbles up as PENDING; we MUST guard before
    # verdict_to_exit (which raises ValueError on PENDING by design).
    # Exit 0 + state.hold_reason populated signals "resume next invocation".
    if verdict == Verdict.PENDING:
        return EXIT_PASS
    return verdict_to_exit(verdict)


def _run(args, env, cwd: Path) -> Verdict:
    """Main pipeline body. Returns Verdict (caller maps to exit code).

    B2-FIX: returns Verdict (not int). main() handles PENDING guard
    + verdict_to_exit mapping. Keeps _run testable without arg-to-exit
    coercion at this layer.

    R3-5 fix: --quiet wired via local warn() lambda. All non-error
    stderr emissions go through warn(); error emissions use direct
    print(..., file=sys.stderr).
    """
    warn = (lambda msg: None) if args.quiet else (
        lambda msg: print("forge: %s" % msg, file=sys.stderr)
    )
    # R4-M2: --state-dir is deprecated v2.1; hardcode to cwd/.forge to match
    # 02-02 StateMachine._persist_state() literal path. Warn if user passed
    # a custom value (signal that v2.0 ignores it).
    if args.state_dir is not None and args.state_dir != ".forge":
        warn("warning: --state-dir is deprecated v2.1; v2.0 always uses "
             "cwd/.forge (your value %r is ignored)" % args.state_dir)
    state_dir = cwd / ".forge"
    state_dir.mkdir(parents=True, exist_ok=True)
    state_path = state_dir / "state.json"
    lock_path = state_dir / "forge.lock"

    # Step 1: mode
    mode = resolve_mode(args.mode, env, sys.stdout.isatty())

    # Step 2: registry
    try:
        registry = load_registry(args.registry)
    except (FileNotFoundError, ValueError) as exc:
        raise CliError("registry load failed: %s" % exc)

    # Step 3: env overrides
    max_rounds = resolve_max_total_rounds(args.max_total_rounds, env)
    max_fix = resolve_max_fix_attempts(args.max_fix_attempts, env)
    engine_choice = resolve_falsification_engine(args.falsification_engine, env)

    # Step 4: baseline / head (H4-FIX: two-phase paths resolution)
    # R4-M1: pass warn lambda so --staged deprecation honors --quiet.
    baseline_spec, head_spec = _build_baseline_specs(args, cwd, warn=warn)
    # Early-phase paths (may be empty for git mode; extracted from diff below).
    initial_paths = _paths(args, cwd, resolved=None)
    try:
        resolved = resolve_baseline(baseline_spec, head_spec, initial_paths, cwd)
    except BaselineResolutionError as exc:
        raise CliError("baseline resolution failed: %s" % exc)
    # Late-phase paths: if user passed none AND we are in git mode,
    # extract changed files from the diff. Non-git empty -> CliError.
    if not initial_paths:
        effective_paths = _paths(args, cwd, resolved=resolved)
        if effective_paths:
            # Re-resolve with extracted paths so source_files is populated.
            resolved = resolve_baseline(
                baseline_spec, head_spec, effective_paths, cwd
            )

    # Step 5: source identity (B3-FIX: keyword args, dispatch on mode_hint)
    if resolved.mode_hint == "git":
        source_hash = compute_source_hash(git_diff=resolved.git_diff or "")
    else:
        source_hash = compute_source_hash(files=resolved.source_files)
    baseline_repr = serialize_baseline_spec(baseline_spec)

    # M6-FIX: non-git snapshot auto-detection (deferred until source_hash known).
    if (resolved.mode_hint == "non-git"
            and args.baseline is None
            and isinstance(baseline_spec, EmptyBaseline)):
        from .snapshot import find_existing_snapshot
        snap_path = find_existing_snapshot(source_hash, cwd)
        if snap_path is not None:
            baseline_spec = SnapshotBaseline(path=snap_path)
            try:
                resolved = resolve_baseline(
                    baseline_spec, head_spec, resolved.source_files, cwd
                )
            except BaselineResolutionError as exc:
                raise CliError(
                    "snapshot baseline resolution failed: %s" % exc
                )
            baseline_repr = serialize_baseline_spec(baseline_spec)

    # Step 6: factories (R3-5: --sandbox warning routed through warn())
    if args.sandbox:
        warn("warning: --sandbox is a Phase 4 hook; ignored in v2.0")
    falsifier = build_falsifier(engine_choice)
    autofixer = build_autofixer(resolved)   # R2-M1: resolved for mode_hint-aware wrap
    revert_fn = build_revert_fn(resolved, cwd)

    # Step 7: lock + run (lock scope covers HOLD-resume loop)
    with ForgeLock(lock_path):
        return _run_hold_loop(
            mode=mode, falsifier=falsifier, autofixer=autofixer,
            revert_fn=revert_fn, resolved=resolved, source_hash=source_hash,
            baseline_repr=baseline_repr, cwd=cwd, registry=registry,
            max_rounds=max_rounds, max_fix_attempts=max_fix,  # R2-B1 fix
            state_path=state_path,
        )


def _run_hold_loop(*, mode, falsifier, autofixer, revert_fn, resolved,
                   source_hash, baseline_repr, cwd, registry,
                   max_rounds, max_fix_attempts, state_path,
                   input_fn=input, output_fn=print) -> Verdict:
    """HOLD-resume loop. CI never HOLDs; LOCAL may re-enter HOLD up to
    MAX_HOLD_CYCLES times. After MAX, treat as ESCALATED.

    M7-FIX: input_fn / output_fn parameterized for test injection
    (default = builtin input / print). Tests pass lambdas returning
    pre-canned responses.

    M3-FIX: access state via load_state (public API) instead of private
    sm._state. load_state returns None on missing file -> use a fresh
    State for the rare "first HOLD entry with no prior state.json"
    edge case (which 02-02 _persist_state should preclude, but the
    public-API path is more robust).
    """
    sm = None
    for cycle in range(MAX_HOLD_CYCLES):
        sm = StateMachine(
            mode=mode, falsifier=falsifier, autofixer=autofixer,
            revert_fn=revert_fn, resolved_review=resolved,
            source_hash=source_hash, baseline_spec_repr=baseline_repr,
            cwd=cwd, registry=registry,
            max_total_rounds=max_rounds, max_fix_attempts=max_fix_attempts,  # R2-B1
        )
        verdict = sm.run()
        if verdict != Verdict.PENDING:
            return verdict
        # M3-FIX: load state from disk (state.json was persisted at HOLD entry
        # per 02-04 _run_local pseudocode); do NOT access sm._state directly.
        from .state import load_state
        loaded = load_state(state_path)
        if loaded is None:
            # Should not happen (HOLD entry persists); defensive.
            return Verdict.ESCALATED
        try:
            run_hold_ui(loaded, state_path, input_fn=input_fn, output_fn=output_fn)
        except HoldAborted as exc:
            print("forge: %s; state preserved at %s" % (exc, state_path),
                  file=sys.stderr)
            return Verdict.PENDING  # caller maps PENDING -> exit 0 (resume signal)
    # M5-FIX: persist infra_errors note on MAX exhaustion via public save_state.
    # R2-L1 cleanup: load_state imported above; only add save_state here.
    # R4-L3 fix: load_state can return None if state.json was deleted mid-run
    # (rare but possible: external cleanup, filesystem race). Fall back to
    # constructing a fresh State so the infra_errors note is still persisted.
    from .state import save_state, State
    final = load_state(state_path)
    if final is None:
        final = State(
            mode=mode, source_hash=source_hash,
            baseline_spec_repr=baseline_repr,
        )
    final.infra_errors.append(
        "MAX_HOLD_CYCLES=%d exhausted; human re-entered HOLD too many times"
        % MAX_HOLD_CYCLES
    )
    final.verdict = Verdict.ESCALATED
    final.converged = False
    save_state(final, state_path)
    return Verdict.ESCALATED


def _build_baseline_specs(args, cwd: Path, warn=None) -> tuple[BaselineSpec, BaselineSpec | None]:
    """Parse --baseline + --head into BaselineSpec union members.

    Defaults per CLI-01:
      git repo: baseline=HEAD, head=WORKING
      non-git:  baseline=empty (first run) or stored snapshot, head=None

    H1-FIX deprecation mapping: --staged -> head=GitRefBaseline("INDEX")
    with stderr warning. If both --staged AND --head provided, --head
    wins (explicit > deprecated).

    M6-FIX: stored snapshot auto-detection -- if non-git AND
    baseline arg absent, probe `.forge/snapshots/` for source_hash
    match (requires compute_source_hash first; that happens in _run
    Step 5 not here, so this function returns EmptyBaseline and
    _run later upgrades to SnapshotBaseline when match found).
    """
    in_git = is_git_repo(cwd)
    if args.baseline is None:
        baseline = GitRefBaseline("HEAD") if in_git else EmptyBaseline()
    elif args.baseline == "empty":
        baseline = EmptyBaseline()
    elif args.baseline.startswith(".forge/snapshots/") or args.baseline.endswith(".json") and "snapshots" in args.baseline:
        # Q1: prefix match accepted v2.0 (panel consensus R1 Q1).
        # M4-FIX: also accept absolute paths containing "snapshots/...json"
        # (fragile prefix-match alone fails on absolute path inputs).
        # Stricter typed prefix `snapshot:<path>` is v2.x candidate per Q1.
        baseline = SnapshotBaseline(path=Path(args.baseline))
    else:
        baseline = GitRefBaseline(args.baseline)
    # R2-M4 fix: warn ANY time --staged is set (not only when --head absent),
    # so users get the deprecation signal even if they mix flags.
    # R4-M1 fix: route warning through warn() lambda so --quiet suppresses it.
    # warn=None fallback prints unconditionally (callers in test paths may
    # omit warn for simplicity).
    if args.staged:
        msg = ("warning: --staged is deprecated; use --head INDEX "
               "(will be removed in v2.1)")
        if warn is not None:
            warn(msg)
        else:
            print("forge: %s" % msg, file=sys.stderr)
    if args.staged and args.head is None:
        head = GitRefBaseline("INDEX")
    elif args.head is None:
        head = GitRefBaseline("WORKING") if in_git else None
    else:
        head = GitRefBaseline(args.head)
    return baseline, head


def _paths(args, cwd: Path, resolved=None) -> list[Path]:
    """H4-FIX: derive paths from explicit args OR extracted from git_diff.

    Without this, `forge --mode=ci` (no positional paths) in a git repo
    runs L0 against empty file list -> false PASS. Spec requires CI to
    review the changed files; explicit paths just filter further.

    Two-phase resolution:
      1. If args.paths non-empty: use them as-is.
      2. If args.paths empty AND resolved (git mode with diff): extract
         changed files from resolved.git_diff via Phase 1 helper.
      3. If args.paths empty AND non-git: raise CliError("non-git mode
         requires paths") per CLI-01.

    _run() calls this twice: once early with resolved=None (raises if
    truly empty non-git); once after resolve_baseline with resolved set
    (extracts from git_diff when paths empty).
    """
    if args.paths:
        return [Path(p) for p in args.paths]
    if resolved is None:
        # Early-phase call: caller will retry with resolved later.
        return []
    if resolved.mode_hint == "git" and resolved.git_diff:
        from .diff import get_changed_files
        return [Path(p) for p in get_changed_files(resolved.git_diff)]
    if resolved.mode_hint == "non-git":
        raise CliError(
            "non-git mode requires explicit paths argument(s); "
            "no files would be reviewed otherwise"
        )
    return []
```

```python
# SPDX-License-Identifier: AGPL-3.0-or-later
"""STATE-10 falsifier + autofixer + revert_fn factories.

Centralizes "which impl do we instantiate" decisions so cli.py stays
declarative and Phase 4 can swap impls without touching the CLI.
"""
from __future__ import annotations

import subprocess
from pathlib import Path
from typing import Callable

from .autofix import AutoFixer, FixOutcome, StubAutoFixer   # FixOutcome for R2-M1 wrapper
from .baseline import ResolvedReview

from .state import StateFinding


def build_falsifier(engine: str) -> Falsifier:
    """STATE-10 engine factory.

    engine = "auto": try Phase 4 import; fall back to stub if absent.
    engine = "stub": always StubFalsifier (test/v2.0 default in practice).
    engine = "real": Phase 4 falsifier (NOT shipped v2.0).
                     explicit "real" raises NotImplementedError with
                     "Phase 4" in the message so users get a clear signal
                     rather than a silent fallback.
    """
    if engine == "stub":
        return StubFalsifier()
    if engine == "auto":
        try:
            from .falsify_real import RealFalsifier   # noqa: F401  (Phase 4)
            return RealFalsifier()
        except ImportError:
            return StubFalsifier()
    if engine == "real":
        try:
            from .falsify_real import RealFalsifier
            return RealFalsifier()
        except ImportError:
            raise NotImplementedError(
                "--falsification-engine=real requires Phase 4 (not shipped "
                "in v2.0). Use --falsification-engine=auto or =stub."
            )
    raise ValueError("unknown engine: %r (expected auto|stub|real)" % engine)


def build_autofixer(resolved: ResolvedReview) -> AutoFixer:
    """v2.0 returns StubAutoFixer; non-git wraps to prevent PARSE_FAIL.

    R2-M1 fix: 02-02 machine.py:336 calls `self.revert_fn(finding)` with
    NO try/except. In non-git mode, revert_fn raises NotImplementedError
    (per B1). The wrapper below converts FixOutcome.PARSE_FAIL ->
    FixOutcome.NO_CHANGE in non-git mode so revert_fn is NEVER invoked
    in non-git autofix loops. Defensive against test misconfig where a
    test injects PARSE_FAIL outcome into StubAutoFixer in non-git mode.

    Real autofixers (Phase 4+) MUST handle their own non-git semantics;
    Phase 4 plan should NOT depend on this wrapper.
    """
    base = StubAutoFixer()
    if resolved.mode_hint == "non-git":
        return _NonGitSafeAutoFixer(base)
    return base


class _NonGitSafeAutoFixer(AutoFixer):
    """R2-M1 wrapper: convert PARSE_FAIL -> NO_CHANGE in non-git mode.

    This prevents StateMachine from calling revert_fn (which raises
    NotImplementedError per B1 in non-git mode). Behavior:
      - PARSE_FAIL -> NO_CHANGE (consumes fix budget; no revert call)
      - SUCCESS / NO_CHANGE / EXCEPTION pass through unchanged
    State machine still promotes CONFIRMED -> UNCERTAIN at MAX after
    repeated NO_CHANGE outcomes; HOLD UX then takes over.

    R3-7 ABC signature verified: fix(self, finding, mode_hint) -> FixOutcome
    byte-equal to 02-02 AutoFixer ABC (src/forge/autofix.py:40).
    """

    def __init__(self, inner: AutoFixer):
        # R3-L4: call super().__init__() for ABC convention (no-op for
        # AutoFixer but matches Python best practice; future ABC additions
        # would inherit init-time setup).
        super().__init__()
        self._inner = inner

    def fix(self, finding: StateFinding, mode_hint: str) -> FixOutcome:
        outcome = self._inner.fix(finding, mode_hint)
        if outcome == FixOutcome.PARSE_FAIL:
            return FixOutcome.NO_CHANGE
        return outcome


def build_revert_fn(resolved: ResolvedReview, cwd: Path) -> Callable[[StateFinding], None]:
    """Build revert_fn for StateMachine constructor.

    Dispatches on resolved.mode_hint:
      "git"     -> git_restore_revert
      "non-git" -> snapshot_restore_revert
    """
    if resolved.mode_hint == "git":
        return _make_git_restore(cwd)
    if resolved.mode_hint == "non-git":
        return _make_snapshot_restore(cwd, resolved)
    raise ValueError("unknown mode_hint: %r" % resolved.mode_hint)


def _make_git_restore(cwd: Path) -> Callable[[StateFinding], None]:
    def _revert(finding: StateFinding) -> None:
        # Restore the file to the index version (undoes autofixer mutation).
        subprocess.run(
            ["git", "restore", "--", finding.file],
            cwd=str(cwd), check=True,
        )
    return _revert


def _make_snapshot_restore(cwd: Path, resolved: ResolvedReview) -> Callable[[StateFinding], None]:
    """B1-FIX: non-git revert is NOT supported in v2.0.

    Root cause: 02-03 Snapshot stores `SnapshotEntry(path, content_hash)`
    -- a list of (path, hash) pairs for BASELINE-03 invalidation
    detection. It does NOT store raw file content. Therefore "revert
    file content from snapshot" is architecturally impossible without
    extending Snapshot schema to v2.

    Decision (R1 B1 option (d)): for v2.0, non-git autofix is functional
    but non-git REVERT is unsupported. revert_fn for non-git raises
    NotImplementedError. Downstream: autofixer.fix() returning PARSE_FAIL
    in non-git mode will propagate the exception to StateMachine, which
    records it in infra_errors and ultimately drives the round to STATE-05
    Category D (infrastructure failure).

    Workaround for users hitting this: use git mode (the dominant path)
    OR avoid autofix in non-git (set autofixer to one that never returns
    PARSE_FAIL, e.g., NO_CHANGE only).

    v2.x candidate: extend Snapshot schema to optionally persist raw
    content for restore. Out of v2.0 scope.
    """
    def _revert(finding: StateFinding) -> None:
        raise NotImplementedError(
            "non-git autofix revert is not supported in v2.0 "
            "(02-03 Snapshot stores content_hash, not raw content). "
            "Use git mode for autofix, or configure autofixer to avoid "
            "PARSE_FAIL outcomes in non-git mode. Tracked as v2.x candidate."
        )
    return _revert
```

```python
"""CLI-03 env override resolution (cli_value > env > default).

FORGE_MODE is intentionally NOT here -- 02-04 resolve_mode owns it.

def resolve_max_total_rounds(cli_value: Optional[int], env: Mapping[str, str]) -> int:
    if cli_value is not None:
        return _validate_int(cli_value, "--max-total-rounds", MAX_REASONABLE_TOTAL_ROUNDS)
    raw = env.get("FORGE_MAX_TOTAL_ROUNDS")

    return _parse_env_int(raw, "FORGE_MAX_TOTAL_ROUNDS", MAX_REASONABLE_TOTAL_ROUNDS)

    if cli_value is not None:
        return _validate_int(cli_value, "--max-fix-attempts", MAX_REASONABLE_FIX_ATTEMPTS)
    raw = env.get("FORGE_MAX_FIX_ATTEMPTS_PER_FINGERPRINT")
    if raw is None or raw == "":
        return MAX_FIX_ATTEMPTS_PER_FINGERPRINT
    return _parse_env_int(raw, "FORGE_MAX_FIX_ATTEMPTS_PER_FINGERPRINT",
                          MAX_REASONABLE_FIX_ATTEMPTS)


def resolve_falsification_engine(cli_value: Optional[str], env: Mapping[str, str]) -> str:
    if cli_value is not None:
        return cli_value
    raw = env.get("FORGE_FALSIFICATION_ENGINE")
    if raw is None or raw == "":
        return "auto"
    key = raw.strip().lower()
    if key not in {"auto", "stub", "real"}:
        raise CliError(
            "invalid FORGE_FALSIFICATION_ENGINE: %r (expected auto|stub|real)" % raw
        )
    return key


def _parse_env_int(raw: str, name: str, sanity_cap: int) -> int:
    # L3-FIX: raw is typed `str` (env values from os.environ are always
    # str when present); AttributeError on .strip() is impossible.
    # ValueError catches int() parse failure including stripped empty.
    try:
        value = int(raw.strip())
    except ValueError:
        raise CliError("invalid %s: %r (expected int)" % (name, raw))
    return _validate_int(value, name, sanity_cap)


def _validate_int(value: int, name: str, sanity_cap: int) -> int:
    if value < 1:
        raise CliError("invalid %s: %d (must be >= 1)" % (name, value))
    if value > sanity_cap:
        raise CliError("invalid %s: %d (exceeds sanity cap %d)"
                       % (name, value, sanity_cap))
    return value
```

## Reviewer Focus (when 02-05-PLAN goes to gsd-review)

- **Phase 1 cli rewrite scope**: how much of existing test_cli.py / test_integration.py should survive untouched? Plan defers to Task 17 audit -- reviewers should verify the audit captures every existing test, not just the obvious ones.

- **MAX_HOLD_CYCLES = 10**: arbitrary bound. Alternatives: env-overridable (FORGE_MAX_HOLD_CYCLES), tied to MAX_TOTAL_ROUNDS, or removed entirely (rely solely on ESCALATED-frozen predicate). Chosen: hardcoded 10 -- ESCALATED-frozen predicate already catches the abusive case; 10 is safety bound for unexpected loop bugs.
- **revert_fn git mode subprocess vs library**: subprocess.run(['git', 'restore']) chosen over GitPython library. Library would avoid forking but adds dependency; CLAUDE.md prefers stdlib. Trade-off documented.
- **HoldAborted exit code = 0**: alternative = new EXIT_PENDING = 5. v2.0 chose 0 because HOLD is non-error semantically; state.hold_reason in state.json signals resume. Reconsider if user reports "exit 0 confused CI script".
- **Engine factory tries import vs feature-flag**: STATE-10 spec says "Phase 4 module importable". Chose `try: import` which probes lazily. Alternative: explicit feature-flag in tools.yaml. Try-import is simpler; matches spec literal.
- **(R3-8 + R4-L1 RESOLVED, can delete during implementation)** revert_fn snapshot dict shape -- entry kept for review trail; reviewers in future plans can ignore. B1 made the snapshot shape concern unreachable; the entry is informational only.
- **CLI flag `--max-fix-attempts` vs env `FORGE_MAX_FIX_ATTEMPTS_PER_FINGERPRINT`**: env name is verbose (matches DISPO-05 constant); flag is shorter. Asymmetric but matches existing pattern.

1. **(R3-L6 acknowledged) `--baseline` snapshot path syntax**: `--baseline .forge/snapshots/<hash>.json` recognized via prefix match + endswith ".json" + "snapshots" in path (R1 M4 strengthened heuristic). 4. **MAX_HOLD_CYCLES env-overridable?**: currently hardcoded 10. Add FORGE_MAX_HOLD_CYCLES if user reports needing more (multi-day review sessions). v2.0 = hardcoded.

But what if user manually edits prior state.json to inject dispositions? CI still skips (per spec). Documented behavior; v2.x may add CI mode warning when prior state.json found.

6. **Phase 1 deprecation message format**: DeprecationWarning category vs custom CliError-with-continue. Current: stderr "warning: --staged is deprecated; use --head=INDEX (will be removed in v2.1)". Avoids Python warnings module noise.
