State machine in 02-02 must be buildable and testable against this stub before the real engine (Phase 4) exists.

## Requirements (6)

- **DISPO-01**: Abstract Disposition enum: CONFIRMED / DISMISSED / UNCERTAIN / FIXED
- **DISPO-02**: Abstract `falsify(finding) -> Disposition` interface; stub returning configurable dispositions for tests
- **DISPO-03**: state.json schema with findings[{id, fingerprint, source: L0|L1, disposition, error?, anchor?, evidence_files?}], dispositions{}, fix_attempts{}, round, mode, source_hash, verdict, converged (bool); inspectable between rounds
- **DISPO-04**: FIXED lifecycle (next-round re-runs tools; gone -> remove; persists -> revert to CONFIRMED + fix_attempts++; new finding = independent entry); "new" precisely = fingerprint not in prior round's active findings
- **DISPO-05**: MAX_FIX_ATTEMPTS exhausted -- LOCAL promote CONFIRMED -> UNCERTAIN exactly once (triggers HOLD); after promotion, L0 re-detection MUST NOT override UNCERTAIN (precedence inversion); human re-CONFIRM -> CONFIRMED frozen + ESCALATED; CI mode has no fix loop so N/A
- **DISPO-06**: Auto-fix failure handling -- if AI auto-fix produces code that fails any L0 parse check, fix reverts (git restore in git mode; snapshot restore in non-git mode), fix_attempts increments, finding stays CONFIRMED

## Disposition Module Design (src/forge/disposition.py)

```python
"""Disposition protocol for forge state machine.

Owned by Phase 2 sub-plan 02-01. All other sub-plans + Phase 4 must conform.
DO NOT add fields without bumping DISPOSITION_PROTOCOL_VERSION.
"""
from enum import Enum
from typing import Final

DISPOSITION_PROTOCOL_VERSION: Final[int] = 1
MAX_FIX_ATTEMPTS_PER_FINGERPRINT: Final[int] = 3  # default; 02-02 may override at runtime
FEEDBACK_SCHEMA_VERSION: Final[int] = 1  # per D7; Phase 7 misses.jsonl reads this for record schema_version field


class Disposition(str, Enum):
    """Finding disposition states.

    State transitions (enforced by state machine, not by enum):
    - (new) -> CONFIRMED | DISMISSED | UNCERTAIN  (set by falsify())
    - CONFIRMED -> FIXED                          (after successful auto-fix)
    - CONFIRMED -> UNCERTAIN                      (DISPO-05 promotion, exactly once per fingerprint)
    - FIXED -> (remove from active)               (next-round re-detect gone)
    - FIXED -> CONFIRMED                          (next-round re-detect persists)
    - UNCERTAIN -> CONFIRMED                      (human re-CONFIRM in HOLD)
    - UNCERTAIN -> DISMISSED                      (human dismiss in HOLD)
    """
    CONFIRMED = "CONFIRMED"
    DISMISSED = "DISMISSED"
    UNCERTAIN = "UNCERTAIN"
    FIXED = "FIXED"
```

## Falsifier Module Design (src/forge/falsify.py)

```python
"""Abstract Falsifier interface + Stub implementation.

Phase 4 will provide the real Falsifier. 02-01 stub allows state machine
to be built and tested without Phase 4.

Note: this module imports `StateFinding` from `forge.state` (NOT the Phase 1
`forge.parsers.base.Finding`). StateFinding is the persisted-in-state.json
representation; parsers.base.Finding is the parser-emitted record. The state
machine (02-02) converts parsers.base.Finding -> StateFinding when populating
state.json.
"""
from abc import ABC, abstractmethod
from pathlib import Path
import json
from typing import Optional

from .disposition import Disposition
from .state import StateFinding


class Falsifier(ABC):
    """Abstract base for falsification engines.

    falsify() must NOT return Disposition.FIXED (FIXED is a state machine
    transition after auto-fix, not a falsifier output).
    """

    @abstractmethod
    def falsify(self, finding: StateFinding) -> Disposition:
        """Classify a finding as CONFIRMED, DISMISSED, or UNCERTAIN.

        Returning FIXED raises ValueError (state machine concern).
        Exception during falsify() MAY be raised; caller (state machine, 02-02)
        catches and converts to UNCERTAIN with error field populated
        (per Phase 4 SC-6). Stub supports raising via fixture "errors" key
        for 02-02 to test the catch path.
        """
        ...


class StubFalsifier(Falsifier):
    """Returns configurable Dispositions for tests; can simulate exceptions.

    Config format (JSON):
      {
        "default": "CONFIRMED",                       # disposition for fingerprints not listed
        "dispositions": {"fp-xxx": "DISMISSED", ...}, # per-fingerprint disposition override
        "errors":       {"fp-yyy": "timeout", ...}    # per-fingerprint: raise RuntimeError(reason)
      }

    Precedence: if a fingerprint is in `errors`, falsify() raises BEFORE consulting
    `dispositions` / `default`. FIXED in any disposition position is rejected at
    constructor time AND at falsify() time (defense in depth).
    """

    def __init__(self, fixture_path: Optional[Path] = None):
        self._dispositions: dict[str, Disposition] = {}
        self._errors: dict[str, str] = {}
        self._default = Disposition.CONFIRMED
        if fixture_path:
            data = json.loads(fixture_path.read_text())
            self._default = Disposition(data.get("default", "CONFIRMED"))
            if self._default == Disposition.FIXED:
                raise ValueError("FIXED is not a valid falsifier output (default)")
            self._dispositions = {}
            for fp, d in data.get("dispositions", {}).items():
                disp = Disposition(d)
                if disp == Disposition.FIXED:
                    raise ValueError(
                        f"FIXED is not a valid falsifier output (fingerprint {fp})"
                    )
                self._dispositions[fp] = disp
            self._errors = dict(data.get("errors", {}))

    def falsify(self, finding: StateFinding) -> Disposition:
        if finding.fingerprint in self._errors:
            raise RuntimeError(
                f"stub-simulated falsification error: {self._errors[finding.fingerprint]}"
            )
        disp = self._dispositions.get(finding.fingerprint, self._default)
        if disp == Disposition.FIXED:
            raise ValueError("FIXED is not a valid falsifier output")
        return disp
```

## State Schema Extension (src/forge/state.py)

Existing Phase 1 state.py has minimal state (Phase 1 `read_state(path) -> dict | None`, `write_state(path, data)` helpers). Phase 2 sub-plan 02-01 **replaces** these helpers with typed `load_state`/`save_state`. Phase 1 callers (audit before implementation: `git grep -nE 'read_state|write_state'` in worktree) migrate to typed API in this sub-plan -- no dual-API period.

**Naming choice (B3 fix)**: The persisted-in-state.json record is named `StateFinding` to avoid conflict with Phase 1's `forge.parsers.base.Finding` (frozen parser-emitted record, different fields). State machine in 02-02 converts `parsers.base.Finding -> StateFinding` when populating state.json.

**State.dispositions vs StateFinding.disposition (H1 resolution)**: DISPO-03 explicitly requires both `findings[].disposition` and `dispositions{finding_id: status}`. The dict is a **derived lookup cache**, not an independent source of truth. Invariants enforced by save/load:
- Source of truth: `StateFinding.disposition` (per-record field)
- Derived cache: `State.dispositions[finding.id] == finding.disposition` for every finding
- `save_state()` rebuilds `dispositions` from findings before write (cache cannot drift on disk)
- `load_state()` verifies cache matches findings; mismatch raises `CorruptedStateError`

```python
"""state.json schema + IO.

Schema owned by 02-01. Subsequent sub-plans add fields ADDITIVELY (no rename,
no remove). Bump SCHEMA_VERSION on breaking change.
"""
from __future__ import annotations
from dataclasses import dataclass, field, asdict
from enum import Enum
from pathlib import Path
from typing import Literal, Optional
import json

from .disposition import Disposition, DISPOSITION_PROTOCOL_VERSION
from .errors import SchemaVersionMismatchError, CorruptedStateError

SCHEMA_VERSION: int = 1


class Mode(str, Enum):
    """Forge execution mode. Resolved by 02-05, consumed by 02-02."""
    LOCAL = "LOCAL"
    CI = "CI"


class Verdict(str, Enum):
    """Process verdict (terminal). Set by state machine on exit."""
    PASS = "PASS"
    FAIL = "FAIL"
    ESCALATED = "ESCALATED"
    PENDING = "PENDING"  # before exit; never persisted on clean shutdown


@dataclass
class StateFinding:
    """A single finding entry in state.json findings[].

    Named `StateFinding` (not `Finding`) to avoid conflict with Phase 1
    `forge.parsers.base.Finding` (parser-emitted record, different shape).
    Conversion: state machine in 02-02 maps parsers.base.Finding -> StateFinding.
    """
    id: str
    fingerprint: str
    source: Literal["L0", "L1"]           # M3: typed source values
    disposition: Disposition
    file: str
    line_range: list[int]                  # M1: list (JSON round-trip preserves), [start, end]
    description: str
    error: Optional[str] = None           # populated when falsify() raised
    anchor: Optional[dict] = None         # before/after snippet for L1 (Anchor TypedDict defined Phase 5)
    evidence_files: Optional[list[str]] = None  # per LAYER1-06


@dataclass
class State:
    """state.json schema. v1."""
    schema_version: int = SCHEMA_VERSION
    disposition_protocol_version: int = DISPOSITION_PROTOCOL_VERSION
    round: int = 0
    mode: Mode = Mode.LOCAL
    source_hash: Optional[str] = None
    findings: list[StateFinding] = field(default_factory=list)
    # Derived lookup cache (NOT source of truth; SOT = StateFinding.disposition).
    # save_state rebuilds from findings; load_state verifies cache matches findings.
    dispositions: dict[str, Disposition] = field(default_factory=dict)  # finding_id -> disposition
    fix_attempts: dict[str, int] = field(default_factory=dict)  # fingerprint -> count
    verdict: Verdict = Verdict.PENDING
    converged: bool = False
    # Fields added by later sub-plans:
    # - baseline_ref (02-03)
    # - lock_pid (02-04, optional)
    # - mode_resolution_source: "tty" | "env" | "flag" (02-05, optional)


def _finding_from_dict(d: dict) -> StateFinding:
    """Explicit reconstruction (B1 fix): JSON -> StateFinding with enum conversion."""
    return StateFinding(
        id=d["id"],
        fingerprint=d["fingerprint"],
        source=d["source"],
        disposition=Disposition(d["disposition"]),
        file=d["file"],
        line_range=list(d["line_range"]),
        description=d["description"],
        error=d.get("error"),
        anchor=d.get("anchor"),
        evidence_files=d.get("evidence_files"),
    )


def load_state(path: Path) -> Optional[State]:
    """Load state.json. Returns None if file does not exist (caller starts fresh).

    Raises:
      CorruptedStateError: JSON parse failure OR derived-cache mismatch with findings.
      SchemaVersionMismatchError: schema_version != SCHEMA_VERSION.
    """
    # B2 fix: missing file is not corruption; per SC-3 caller starts fresh.
    if not path.exists():
        return None
    try:
        data = json.loads(path.read_text())
    except json.JSONDecodeError as e:
        raise CorruptedStateError(f"cannot parse {path}: {e}") from e

    sv = data.get("schema_version")
    if sv != SCHEMA_VERSION:
        raise SchemaVersionMismatchError(
            f"state.json schema_version={sv}, forge expects {SCHEMA_VERSION}; "
            f"remove .forge/state.json to start fresh"
        )

    findings = [_finding_from_dict(f) for f in data.get("findings", [])]
    dispositions = {k: Disposition(v) for k, v in data.get("dispositions", {}).items()}

    # H1 invariant: derived cache must match findings
    expected = {f.id: f.disposition for f in findings}
    if dispositions != expected:
        raise CorruptedStateError(
            f"dispositions cache out of sync with findings (path={path})"
        )

    return State(
        schema_version=data["schema_version"],
        disposition_protocol_version=data["disposition_protocol_version"],
        round=data["round"],
        mode=Mode(data["mode"]),
        source_hash=data.get("source_hash"),
        findings=findings,
        dispositions=dispositions,
        fix_attempts=dict(data.get("fix_attempts", {})),
        verdict=Verdict(data["verdict"]),
        converged=bool(data["converged"]),
    )


def save_state(state: State, path: Path) -> None:
    """Atomic write of state.json. Rebuilds dispositions cache before write."""
    # H1 invariant: cache derives from findings on every save (cannot drift on disk)
    state.dispositions = {f.id: f.disposition for f in state.findings}
    path.parent.mkdir(parents=True, exist_ok=True, mode=0o755)  # per D1
    tmp = path.with_suffix(".tmp")
    tmp.write_text(json.dumps(asdict(state), default=str, indent=2))
    tmp.replace(path)
```
