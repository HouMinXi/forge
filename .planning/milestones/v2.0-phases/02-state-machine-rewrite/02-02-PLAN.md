## Goal

Ship the loop-until-fixpoint state machine. Driver of forge's per-round lifecycle: invoke L0 runner, classify L1 findings via `Falsifier`, apply LOCAL auto-fix loop (consuming `AutoFixer` stub), detect fixpoint / HOLD entry / MAX_TOTAL_ROUNDS exhaustion, classify non-convergence as A/B/C/D, emit terminal `Verdict`. Mode (LOCAL / CI) is a constructor parameter -- mode resolution (TTY / env / flag) is 02-04 / 02-05 scope.

State machine consumes 02-01 (`Disposition`, `StateFinding`, `State`, `StubFalsifier`) + 02-03 (`ResolvedReview`, `compute_source_hash`) + Phase 1 (`run_tools`, `parse_output`, parsers). Plus DISPO-04/05/06 behavior tests moved from 02-01 per H4 of 02-01 R1 review.

## Requirements (10 = 7 plan reqs + 3 H4-moved behavior tests)

- **STATE-01**: Loop-until-fixpoint state machine bounded by `MAX_TOTAL_ROUNDS`
- **STATE-02**: Two mode branches -- LOCAL (loop, auto-fix CONFIRMED, ask on UNCERTAIN) and CI (linear, FAIL on CONFIRMED, no fix loop)
- **STATE-03**: CI mode is linear (no fix loop, CONFIRMED fails build immediately, UNCERTAIN emits warning)
- **STATE-04**: `MAX_TOTAL_ROUNDS = 20` + `MAX_FIX_ATTEMPTS_PER_FINGERPRINT = 3` bounds (LOCAL mode); ESCALATED on `MAX_TOTAL_ROUNDS` reached without convergence
- **STATE-05**: Non-convergence A/B/C/D diagnosis on ESCALATED. A = FIXED-to-CONFIRMED oscillation; B = new CONFIRMED each round; C = UNCERTAIN accumulation; D = infrastructure failure (L0 all-tools-fail per LAYER0-06, or `falsify()` repeated exceptions)
- **GATE-01b**: HOLD = non-terminal LOCAL-mode pause when UNCERTAIN remain AND no unfixed CONFIRMED. Resolves to PASS / FAIL / ESCALATED via DISPO-05 path
- **GATE-03**: PASS verdict conditionally deterministic given complete disposition ledger (every CONFIRMED reached terminal FIXED/DISMISSED; every UNCERTAIN dispositioned in LOCAL OR emitted as warning in CI)
- **DISPO-04** (behavior tests, moved from 02-01 H4): FIXED lifecycle -- gone next round = remove; persists = revert to CONFIRMED + `fix_attempts++`; new fingerprint = independent entry
- **DISPO-05** (behavior tests, moved from 02-01 H4): `MAX_FIX_ATTEMPTS_PER_FINGERPRINT` exhausted -- promote CONFIRMED -> UNCERTAIN exactly once; L0 re-detect MUST NOT re-CONFIRM (FP-04 exception path). NOTE per R1 B5 + **R2-3**: "human re-CONFIRM in HOLD -> ESCALATED frozen" requires 02-04 HOLD-resume special exit logic AND human UX -- **deferred to 02-04 entirely**. 02-02 covers (a) one-time promotion and (b) post-promotion L0 stickiness only. The ESCALATED-frozen exit (re-CONFIRMED post-promotion -> immediate ESCALATED without waiting for MAX_TOTAL_ROUNDS) is 02-04's responsibility because it introduces a new exit predicate that needs HOLD-state context not present in 02-02.
- **DISPO-06** (behavior tests, moved from 02-01 H4): Auto-fix produces parse-error code -> revert (git restore git-mode / snapshot restore non-git mode) + `fix_attempts++` + stays CONFIRMED. Per R1 B2: revert mechanism = `revert_fn: Callable[[StateFinding], None]` injected into StateMachine constructor. StubAutoFixer returns FixOutcome (no I/O); state machine calls `revert_fn(finding)` on PARSE_FAIL. Real revert_fn (Phase 4) provides `git restore` / snapshot restore.

```python
"""State machine core: loop-until-fixpoint orchestration.

Owned by 02-02. Mode-agnostic core; mode (LOCAL / CI) is a constructor
parameter (D3). Mode resolution (TTY / env / flag) is 02-04 + 02-05.

Per-round flow:
  1. Run L0 (Phase 1 runner) -> auto-CONFIRMED StateFindings (GATE-04a + FP-04)
  2. Collect L1 candidate findings (Phase 5 not shipped; 02-02 accepts injected
     list for tests; production list is [] in v2.0 Phase 2)
  3. For each L1 candidate: falsifier.falsify() -> Disposition.
     RuntimeError from falsify() -> finding becomes UNCERTAIN with error field
     populated (per Phase 4 SC-6 contract; B4 from 02-01 review).
  4. Merge by fingerprint (FP-04: L0 wins over L1 disposition; DISPO-05 promotion
     UNCERTAIN sticks against L0 re-detect)
  5. LOCAL mode: for each unfixed CONFIRMED, invoke autofixer
     - success -> FIXED
     - parse_fail -> revert + fix_attempts++ (DISPO-06)
     - fix_attempts >= MAX -> promote CONFIRMED -> UNCERTAIN once (DISPO-05)
  6. CI mode: skip auto-fix loop; CONFIRMED count > 0 -> FAIL exit immediately
  7. Update state.round_history snapshot; save_state.
  8. Convergence check: zero NEW CONFIRMED this round (new = fingerprint not in
     prior round's active findings; DISPO-04 "new" definition)
  9. HOLD check (LOCAL only): UNCERTAIN > 0 AND unfixed_CONFIRMED == 0 -> HOLD
"""

from __future__ import annotations

from dataclasses import dataclass, field

from .autofix import AutoFixer, FixOutcome
from .baseline import ResolvedReview

# L1 candidate provider: zero-arg callable returning fresh StateFindings each round.
# Phase 2 ships with default = () lambda; Phase 5 plugs in real L1 pipeline.
L1Provider = Callable[[], list[StateFinding]]


@dataclass
class StateMachine:
    """Forge state machine. Constructor wires dependencies; .run() executes.

    Parameters:
      mode: Mode.LOCAL or Mode.CI
      falsifier: Falsifier impl (StubFalsifier for tests, real for Phase 4)
      autofixer: AutoFixer impl (StubAutoFixer for tests, real for Phase 4)
      revert_fn: Callable[[StateFinding], None] -- invoked by state machine on
        FixOutcome.PARSE_FAIL (B2 fix from R1). StubAutoFixer is pure (returns
        outcome only); revert is a separate concern. Test wires a recording mock;
        Phase 4 production wires git restore (git mode) / snapshot restore
        (non-git mode) selecting strategy via resolved_review.mode_hint.
      post_round_hook: Optional callable invoked at end of each round with the
        completed round_index. Test observability for SC-14 mid-loop verification
        (H6 fix from R1). Default None = no-op. Phase 4+ may use for telemetry.
      resolved_review: from 02-03 resolve_baseline (drives L0 file scope +
        revert_fn strategy selection)
      source_hash: from 02-03 compute_source_hash (for state.json STATE-07)
      baseline_spec_repr: from 02-03 serialize_baseline_spec (for state.json)
      cwd: working directory (state.json path = cwd/.forge/state.json)
      l1_provider: optional callable returning list[StateFinding] for L1
        candidates this round. Default = no L1 (Phase 5 will plug in real).
      max_total_rounds: STATE-04 LOCAL bound (default from env or 20)
      max_fix_attempts: per-fingerprint fix budget (default from disposition.MAX)
      l0_runner: callable taking (registry, files) -> tuple[list[StateFinding], list[str]]
        per R2-1 fix. First element: StateFindings with disposition=CONFIRMED;
        second element: ToolError messages to append to State.infra_errors.
        Caller (_execute_round) MUST unpack both. Injectable for tests.
      registry: dict[str, ToolConfig] (Phase 1 registry passed to l0_runner)
    """
    mode: Mode
    falsifier: Falsifier
    autofixer: AutoFixer
    revert_fn: Callable[[StateFinding], None]
    resolved_review: ResolvedReview
    source_hash: str
    baseline_spec_repr: str
    cwd: Path
    registry: dict
    l0_runner: Callable
    l1_provider: L1Provider = field(default=lambda: [])
    post_round_hook: Optional[Callable[[int], None]] = None
    max_total_rounds: int = 20
    max_fix_attempts: int = MAX_FIX_ATTEMPTS_PER_FINGERPRINT
    _state: State = field(default_factory=State, init=False)

    def run(self) -> Verdict:
        """Dispatch to LOCAL or CI execution per mode."""
        self._state.mode = self.mode
        self._state.source_hash = self.source_hash
        self._state.baseline_spec_repr = self.baseline_spec_repr
        if self.mode == Mode.LOCAL:
            return self._run_local()
        if self.mode == Mode.CI:
            return self._run_ci()
        raise ValueError("unknown mode: %s" % self.mode)

    def _run_ci(self) -> Verdict:
        """CI: linear single round; FAIL on any CONFIRMED, else PASS.

        STATE-03 / STATE-09 (no state.json inherit) -- but STATE-09 fresh-start
        enforcement is 02-04 scope; this method assumes mode=CI was set fresh.
        UNCERTAIN non-blocking (emitted as warning by output layer 02-06).

        Per R1 H5 fix: converged semantics = "machine reached terminal verdict
        through normal convergence". CI FAIL exits early (CONFIRMED present);
        therefore converged=False on FAIL, converged=True on PASS only.
        """
        self._execute_round(round_index=0)
        confirmed = self._count(Disposition.CONFIRMED)
        verdict = Verdict.FAIL if confirmed > 0 else Verdict.PASS
        self._state.verdict = verdict
        self._state.converged = (verdict == Verdict.PASS)
        self._persist_state()
        return verdict

    def _run_local(self) -> Verdict:
        """LOCAL: loop until fixpoint / HOLD / MAX_TOTAL_ROUNDS.

        STATE-01 / STATE-02 / STATE-04 / STATE-05 / GATE-01b.
        """
        for round_index in range(self.max_total_rounds):
            self._execute_round(round_index)
            self._apply_autofix_loop()
            if self._fixpoint_reached():
                self._finalize_local_terminal()
                return self._state.verdict
            if self._should_enter_hold():
                # GATE-01b: HOLD is non-terminal pause; return PENDING.
                # 02-04 handles human interaction + resume; 02-02 only marks state.
                self._state.verdict = Verdict.PENDING
                self._persist_state()
                return Verdict.PENDING

        # MAX_TOTAL_ROUNDS exhausted -> STATE-05 diagnosis + ESCALATED
        category = diagnose_non_convergence(
            self._state.round_history, self._state.infra_errors
        )
        self._state.verdict = Verdict.ESCALATED
        self._state.converged = False
        self._state.infra_errors.append("ESCALATED category=%s" % category)
        self._persist_state()
        return Verdict.ESCALATED

    def _execute_round(self, round_index: int) -> None:
        """One round: L0 + L1 falsify + merge + state update + snapshot.

        Auto-fix loop is _apply_autofix_loop (LOCAL only); separated so
        CI path skips it.
        """
        self._state.round = round_index

        # 1. L0 runner -> auto-CONFIRMED per GATE-04a + FP-04
        # R2-1 fix: l0_runner returns (findings, infra_errors) tuple; unpack here.
        try:
            l0_findings, l0_infra = self.l0_runner(
                self.registry, self._source_files()
            )
            self._state.infra_errors.extend(l0_infra)
        except Exception as exc:  # noqa: BLE001 (catch-all for infra signal)
            self._state.infra_errors.append("L0 runner failed: %s" % exc)
            l0_findings = []

        # 2. L1 candidates (Phase 2 stub provider; Phase 5 plugs real L1)
        l1_candidates = self.l1_provider()

        # 3. Falsify each L1 candidate
        l1_findings: list[StateFinding] = []
        for f in l1_candidates:
            try:
                disposition = self.falsifier.falsify(f)
                f.disposition = disposition
            except RuntimeError as exc:
                # B4 contract: stub error -> UNCERTAIN + error field populated
                f.disposition = Disposition.UNCERTAIN
                f.error = "falsify() raised: %s" % exc
                self._state.infra_errors.append(
                    "falsify exception on %s: %s" % (f.fingerprint, exc)
                )
            l1_findings.append(f)

        # 4. Merge by fingerprint -- FP-04 precedence (L0 wins; promoted UNCERTAIN sticks)
        merged = self._merge_findings(l0_findings, l1_findings)

        # 5. Apply DISPO-05 promotion stickiness against prior round
        merged = self._apply_promotion_stickiness(merged)

        self._state.findings = merged
        self._append_round_snapshot(round_index, l0_findings, l1_findings)
        self._persist_state()
        if self.post_round_hook is not None:
            self.post_round_hook(round_index)  # H6 test observability

    def _fixpoint_reached(self) -> bool:
        """R1 B3 + R2-2 fix: precise fixpoint definition (LOCAL only).

        TRUE iff ALL FOUR conditions hold for the just-completed round:
          (a) zero NEW fingerprints entered CONFIRMED this round
              (new = fingerprint not present in the prior round_history entry
               at any disposition; first-round CONFIRMEDs ARE new -- so a
               round 0 with any CONFIRMED is NOT a fixpoint).
          (b) zero FIXED findings reverted to CONFIRMED this round
              (FIXED in prior round AND CONFIRMED in current round per
               fingerprint; DISPO-04 "FIXED persists" path is a revert).
          (c) zero unfixed CONFIRMED remain in the current active findings
              (R2-2 BLOCKER fix: without this, a persistently-CONFIRMED
               finding whose autofixer returns NO_CHANGE would satisfy
               (a)+(b) and produce wrong PASS verdict.)
          (d) zero UNCERTAIN remain in the current active findings
              (R2-2 BLOCKER fix: GATE-03 SC-7 requires LOCAL PASS =
               "every UNCERTAIN dispositioned"; without (d) the HOLD
               check would never be reached -- UNCERTAIN-only states
               would incorrectly resolve to PASS instead of HOLD/PENDING.)

        Mimo #1 ambiguity resolution: a FIXED->CONFIRMED reversion is
        NOT a "new CONFIRMED" (its fingerprint existed last round) but it
        IS a revert. (a) and (b) are independent.

        Mode note: CI never calls _fixpoint_reached() (linear single-round
        exit via _run_ci). CI's PASS criterion is "zero CONFIRMED" only
        (UNCERTAIN non-blocking in CI -- emitted as warning).

        Round 0 boundary (R3 LOW4): when called after _execute_round(0)
        there is no prior round_history entry. Conditions (a) and (b)
        require comparison against prior round; on round 0 the prior
        "round" is treated as the empty set, so:
          - any CONFIRMED active in round 0 satisfies (a)=NEW (fails (a))
          - (b) trivially holds (no prior FIXEDs to revert)
        Net: round 0 produces fixpoint=True iff zero CONFIRMED AND zero
        UNCERTAIN. Equivalent to "L0+L1 found nothing" trivial PASS.
        """
        ...

    def _finalize_local_terminal(self) -> None:
        """R3 LOW5: terminal state writer for LOCAL fixpoint exit.

        Called from _run_local() when _fixpoint_reached() returns True.
        Sets verdict = Verdict.PASS, converged = True, persists state.
        (FAIL terminal is not reachable in LOCAL fixpoint path; LOCAL FAIL
        is ESCALATED via MAX_TOTAL_ROUNDS exhaustion which is handled
        directly in _run_local() after the loop, not here.)
        """
        self._state.verdict = Verdict.PASS
        self._state.converged = True
        self._persist_state()

    # ... (helper methods: _apply_autofix_loop, _should_enter_hold,
    #      _finalize_local_terminal, _merge_findings, _apply_promotion_stickiness,
```

```python
        from `.parsers.base` (file, line, end_line, column, rule_id,
        message for Finding; tool_name, exit_code, stderr, message for
        ToolError -- verified in plan against
        src/forge/parsers/base.py lines 14-65).
      - `run_tools` from `.runner` returns dict[str, ParseResult] keyed
        by tool name (verified Phase 1 runner.py:run_tools signature).

    Returns: (state_findings, infra_error_messages)
    """
    import hashlib
    from .parsers.base import Finding, ToolError  # Phase 1 imports
    from .runner import run_tools

    tool_results, _tool_versions, _tools_skipped = run_tools(registry, files)
    state_findings: list[StateFinding] = []
    infra_errors: list[str] = []
    for tool, result in tool_results.items():
        for item in result.findings:
            if isinstance(item, ToolError):
                infra_errors.append(
                    "L0 ToolError tool=%s msg=%s" % (tool, item.message)
                )
                continue
            f: Finding = item
            fp_raw = "%s:%s:%s:%s" % (tool, f.file, f.line, f.rule_id)
            fp = hashlib.sha256(fp_raw.encode("utf-8")).hexdigest()[:16]
            state_findings.append(
                StateFinding(
                    id=fp,
                    fingerprint=fp,
                    source="L0",
                    disposition=Disposition.CONFIRMED,
                    file=f.file,
                    line_range=[f.line, f.end_line],  # R3 LOW1: list per state.py:51
                    description=f.message,
                    error=None,
                    anchor=None,
                    evidence_files=[],
                )
            )
    return state_findings, infra_errors
```
