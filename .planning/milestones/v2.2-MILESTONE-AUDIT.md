## Gap Analysis

**One actionable gap preventing full BACKEND-01 satisfaction:**

`load_backend_configs()` exists in `backend.py` but is never called. The fix is
2-5 lines in `cli.py:_run()`: load a config file (gate.yaml or a dedicated
backends.yaml), call `load_backend_configs(config_data)`, and pass the result
to `resolve_backend(env, configs=configs, cli_value=...)`. This is the exact
wiring the planned v2.3 mimo/custom-backend feature will provide.

**Assessment:** This is a pre-existing gap that v2.3 will close. It does not
break any currently working feature (DEFAULT_BACKEND session-model works fine).
Users who want mimo/deepseek backends are already aware they need v2.3.
