### Issue Found During Full Suite (Task 5)

**Test regression:** `test_run_contracts_guard_catches_exception` failed
on first full-suite run. Root cause: the new `args.focus` attribute on
MagicMock (truthy by default) triggered the focus file-loading path
before the contracts guard, preventing the test from reaching the
asserted code path.

**Fix:** Added `args.focus = None` to the test mock (commit `b0b4d03`),
matching the existing pattern for `args.backend_url = None` etc.
Second full-suite run: 2903 passed, 0 failed.

**Classification:** Pre-existing mock gap exposed by new feature, not a
design defect. The fix is a standard mock-setup update.
