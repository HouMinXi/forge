<objective>
Give CI-mode review runs cross-run memory: consume the ledger that 44-01
writes, so a known-and-resolved finding never re-blocks, a human rebuttal
suppresses via the same ledger, pinned paths are honored, style findings
stop blocking, and CI converges when nothing new remains.

Purpose: EVAL-02 read side, from the review pain-points work order (12
rounds / 39 receipts, 52% repeat findings, 19% useful density -- root cause
STATE-09 CI zero-memory). 44-01 writes the ledger; this plan READS it to
converge. Output: a suppression pass in _run_ci + the read-side helpers.

SCOPE OF THE FIX (honest expectation, per CP1 W-3): this plan suppresses
VERBATIM re-finds -- the same finding (same file:line:desc fingerprint) on
an unchanged-diff CI re-run, and findings a human already ruled via
adjudicate. That is the dominant repeat mode the STATE-09 root cause
produces. It does NOT suppress (a) reworded re-finds of the same underlying
issue (the R5/R7 case) or (b) line-drifted re-finds (same bug, same wording,
after the file shifts -- the fingerprint covers line, so drift escapes
suppression). Both persist BY DESIGN: fuzzy/topic matching is a false-green
risk and is rejected. Those two classes are a reviewer-behavior problem, out
of scope here.
</objective>
