    MCP-08 (HIGH): The current trust model hashes the entire backends block. Any byte
    change (including a model name bump) invalidates trust and requires the full
    re-ceremony. Fix: hash only the dangerous fields for trust invalidation.

    IMPORTANT: trust.py already defines DANGEROUS_FIELDS frozenset (line 23-31) =
    {base_url, api_key_env, api_key_file, shell, command, hook, credentials_path}.
    Use this EXISTING frozenset as the authoritative list -- do NOT invent a new
    subset. shell/command/hook control arbitrary execution (CWE-78) and MUST
    invalidate trust if changed. api_key_cmd does NOT exist in BackendConfig.

    Implementation: In trust.py hash_backends_block (line 86-96), change from hashing
    the entire backends YAML block to: iterate each backend entry, extract only fields
    present in DANGEROUS_FIELDS, hash that subset. Model name, temperature, max_tokens
    etc. are safe to change without re-trust.
    The dangerous fields are those that could be used to exfiltrate code or execute
    arbitrary commands: base_url, api_key_env, api_key_file, credentials_path, shell,
    command, hook (the existing DANGEROUS_FIELDS frozenset). All other fields (model,
    provider, format, temperature, max_tokens, stream, etc.) are safe to change without
    re-trust. Add a guard test: hash a config, change model -> hash unchanged; change
    base_url -> hash changed. MIGRATION: existing trust stores use the old all-fields
    hash. After this change, every user's trust hash mismatches on first run. Handle:
    on is_trusted() mismatch, try the old all-fields hash as fallback -- if THAT
    matches, auto-migrate the stored hash to the new dangerous-fields-only format
    (one-time silent upgrade). If neither matches, require re-trust as before. This
    avoids a forced re-trust ceremony for every existing user.

    MCP-05 (MEDIUM): This is a consequence of MCP-08. Once trust only hashes dangerous
    fields, a model bump no longer invalidates trust. Add a user-facing message when
    trust IS invalidated: print to stderr "Trust invalidated: credential-related fields
    changed in gate.yaml. Run 'code-forge trust' to re-authorize."
