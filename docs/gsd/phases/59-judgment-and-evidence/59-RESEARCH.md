### First dialect: manual Chat tool protocol

[CITED: developers.openai.com/api/docs/guides/function-calling; VERIFIED: context7-chat-tools.json] Chat calls use assistant tool_calls and tool results with tool_call_id; a legitimate tool reply may have content=null. Strict function schemas require runtime validation regardless of provider adherence. Use stream=false and parallel_tool_calls=false. Full tool-call parsing is a distinct adapter; the existing SSE assembler only accumulates text and must not dispatch argument fragments. Responses correlation IDs are a different dialect.

[PROPOSED] Advertise exactly read_source, query_calls and replay_review_envelope. For each response:
1. Persist bounded acquired HTTP bytes, decoded assistant content and full raw tool arguments before transformations, with layer labels.
2. Require exactly one choice, known finish state and complete supported function call. Reject duplicate/unknown IDs/types, invalid JSON arguments, extra fields, more than one tool request or both ambiguous final text and tool requests.
3. Validate fixed argument schema and trusted snapshot/policy. Append the complete assistant tool_calls message followed by one matching tool message; only complete validated calls dispatch.
4. Refusal/content_filter, unsupported tool capability, unknown stop state, length/partial tool arguments, denied tool or exhausted budget terminates investigation incomplete. Never run partial arguments or parse prose as calls.
5. Final text alone passes the existing parser/strict factory validators. Allow one bounded final-envelope correction and one excerpt repair under the same pool. Text-final truncation can use recorded bounded legacy recovery only within its declared sub-budgets; partial tool requests cannot use string stitching.
6. Model/source/tool messages cannot set budgets, run IDs, repository roots, recipe identity, acceptance flags or shell/SQL. Provider names/IDs are metadata, never filenames.

[PROPOSED] Declared dialect config must protect tools/tool_choice/messages/n/stream/parallel_tool_calls and generated schemas against generic backend.params overrides. Profile admission fails explicitly for mismatched backend format/model/effort/endpoint. Do not mutate existing BackendConfig or configured shared params during wider retries.
